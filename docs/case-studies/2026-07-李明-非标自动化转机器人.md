# 案例：非标自动化 → 机器人结构设计（虚拟用户"李明"）

> 数据来源：career-advisor 的 examples/ 测试示例（profile / decision / city / company / summary）
> 诚实声明：**李明是虚拟测试用户**，用于演示系统完整决策链，非真实个人案例。
> 案例中的公司为化名（苏舟智），数据为示例数据。

---

## 背景

李明，28 岁，本科机械工程，非标自动化机械工程师（常州），5 年经验。

- 核心技能：SolidWorks 3D 设计（精通）、非标自动化方案设计（精通）、机械传动/气动选型（熟练）、项目管理（熟练，带过 3 人小组、管过 2 个 300 万+ 项目）
- 弱项：无机器人学理论基础、无 ROS 经验、伺服/电机控制仅限选型不会调试、英语口语弱
- Gap：10 个月考研空档（机器人工程方向，未上岸），存款 12 万（约 8 个月生活费），单身无房贷
- 诉求：想从非标自动化转到机器人方向，但不知道：能不能转、怎么转、第一步做什么

## 决策链（系统实际输出的摘要）

### 第 1 站：转行可行性分析（career-transition）

| 维度 | 结果 |
|------|------|
| 目标方向 | 机器人本体设计（入口 A 快速通道） |
| 技能重叠度 | 4/9 ≈ 44%（30-50% 档）→ 跳板路径 |
| 财务缓冲 | 12 万 ≈ 8 个月生活费 → Q1 软着陆 |
| 风险调节系数 | 0.935 |
| 关键风险 | 机器人传动/减速器经验为零，需 3-6 个月补强 |
| 结论 | **能转，走跳板路径（非标自动化 → 机电一体化 → 机器人），先在职补齐差距，不裸辞** |

系统没有说"可以实现"——它给了具体的跳板路径和 3-6 个月的补强期。

### 第 2 站：城市评估（city-advisor）

| 维度 | 结果 |
|------|------|
| 城市 | 苏州（对比深圳后选择） |
| 总分 | 8.2/10（中置信度） |
| 机器人产业聚集度 | 9/10（汇川/埃斯顿/节卡/艾利特/绿的谐波总部） |
| 岗位密度 | 8/10（结构工程师岗位充足，2025 年招聘量 +25%） |
| 产业链完整度 | 9/10（减速器 → 本体 → 集成 → 应用全覆盖） |
| 关键风险 | 房价收入比偏高（工业园区均价 3.5 万/㎡） |
| 薪资可行性 | 可行 |

产业匹配度 9/10 是决定性因素：常州到苏州的距离意味着软着陆的试错成本极低。

| 字段 | 值 |
|------|-----|
| 方向匹配度 | 75%（中置信度） |
| 城市得分 | 8.2/10（中置信度） |

**最终建议**：方向可行、城市选苏州、公司可选但需交叉验证现金流——先在职完成差距补强（3-6 个月），同时接触 2-3 家备选公司，不把鸡蛋放在一家创业公司里。

## 这个案例展示了什么

1. **决策链是完整的**——从"我想转机器人"一句话，到"苏州 + 跳板路径 + 3-6 个月补强计划 + 公司短名单"，每一步都有数据支撑和可追溯的来源
2. **系统拒绝制造虚假希望**——44% 技能重叠度没有包装成"你非常适合"；创业公司的现金流风险没有被融资光环掩盖
3. **每站输出都可衔接下一站**——转行分析的城市偏好喂给城市评估，城市评估的结果喂给公司筛选，最终汇总成一份结论
4. **人的决策权保留**——系统输出的是"建议 + 风险 + 下一步"，最终"去不去苏州、投不投苏舟智"由李明自己决定
