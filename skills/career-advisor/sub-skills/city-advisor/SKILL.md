# 求职向城市选择
>
> 本文件是 career-advisor skill 的子模块。由主 SKILL.md 路由加载，不作为独立 skill 运行。

**输入你的职业和偏好，输出最适合你发展的城市排序。**

不预设城市偏好，不从旅游/美食角度出发——从产业匹配度、薪酬性价比、职业天花板、成长土壤、
人才政策、生活适配、城市群生态七个维度，用公开信号加权评分。

---

## 依赖

| 工具 | 来源 | 状态 | 说明 |
|------|------|:----:|------|
| `WebSearch` | Claude Code 内置 | 必选 | 中文搜索主通道 |
| `WebFetch` | Claude Code 内置 | 必选 | 深度阅读薪资报告、政策文件 |
| `Exa web_search_exa` | ECC 插件内置 MCP | 强烈推荐 | 中文搜索质量远超 WebSearch |
| `mcp-cnbs` | 项目 `.mcp.json` | 强烈推荐 | 国家统计局 API，27+ 工具 |
| `Agent` | Claude Code 内置 | 推荐 | 7维度搜索用 Agent 并行派发 |

### 核心工具：mcp-cnbs

通过项目根目录 `.mcp.json` 配置，提供以下能力：
- `cnbs_economic_snapshot()` — 全国经济速览（GDP/CPI/PMI/失业率等10项指标）
- `cnbs_search("可支配收入 省份")` — 按关键词搜索指标
- `cnbs_compare("人均GDP", ["北京","上海","深圳"], "city")` — 跨城市对比
- `ext_cn_census("population")` — 人口普查数据

### WebSearch 不可用时的降级策略

1. 将全部搜索负载转移到 Exa
2. 报告末尾标注"本次搜索 WebSearch 不可用，部分信号源未被检索"

## 与 company-screener / company-research 的关系

```
city-advisor (城市选择层)     →  "我该去哪个城市？"
        ↓ 人工接力
company-screener (发现层)      →  "这个城市有什么好公司？"
        ↓ 人工接力
company-research (评估层)      →  "这家公司值不值得去？"
        ↓
你决策                       →  投简历/面试/接offer
```

**三个 skill 独立运行。** city-advisor 零文件依赖另外两个 skill。

## 工作流总览

```
Step 1: 四问定框架 → 职业 + 阶段 + 学校/专业 + 偏好维度
Step 2: 职业推理   → Read references/career-industry-map.md
Step 3: 候选城市确定 → 用户指定 / 城市群对比 / 三选一
Step 4: 7维度并行搜索 → 产业/薪酬/天花板/成长/政策/生活/城市群
Step 5: 加权打分+排序 → Read references/city-scoring-model.md
Step 6: 输出推荐报告 → Read references/advisor-template.md
```

---

## Step 1: 四问定框架

不要一次性抛出四个问题。依次问，根据上一个回答决定下一个问题的呈现方式。

### 问题一：职业定位

```
你是做什么的？（自由输入）
例如："机械工程师"、"嵌入式开发"、"Java后端"、"电池工艺工程师"、"还没定方向"
```

- "还没定方向" → 问有没有感兴趣的行业，没有则通用搜索

### 问题二：人生阶段

```
你现在是什么阶段？
A. 应届/初入职场（0-3年） → 产业集聚+成长土壤优先
B. 成长期（3-6年）        → 薪资+职业天花板优先
C. 定居/跳槽（6年+）      → 生活品质+人才政策优先
```

阶段决定默认权重矩阵。详见 `references/city-scoring-model.md`。

### 问题三：学校与专业

```
在哪上的学？（可选，但对评估校友网络和政策加分有帮助）
- 学校名称：
- 学校层次：985 / 211 / 双一流 / 省重点 / 普通本科 / 专科
- 专业名称：
- 专业实力：全国前10 / 前50 / 省级重点 / 普通
```

- 用户说"不方便透露"或跳过 → 不影响主流程，跳过校友网络加分
- 学校层次和专业的就业影响力说明：
  - 985/211/双一流 → 全国认可，不限地域
  - 省重点 → 本省认可度高，跨省打7折（仅在成长土壤维度体现）
  - 普通本科 → 本地认可为主，跨省打5折
  - 王牌专业（全国前10）→ 对口产业城市有天然适配

### 问题四：偏好权重

```
最看重什么？（可多选）
A. 产业集聚/岗位多 — "工作机会多，跳槽选择面广"
B. 薪资高/房租低   — "到手多，每月剩的多"（租房负担率子权重额外 +10%）
C. 行业龙头/天花板高 — "有大厂，职业上限高"
D. 高校资源/技术氛围 — "学习环境好，同行交流方便"
E. 人才补贴/落户容易 — "政策好，政府给钱"
F. 离家近/气候好   — "生活舒适，离家人近"
G. 都看重           → 用阶段默认权重，不调整
```

用户选择后，在阶段默认权重基础上 ×1.5 调整对应维度，然后重新归一化。

## Step 2: 职业推理

Read `references/career-industry-map.md`，从职业反推行业簇 + 国家级产业集群标签。

确认语示例：
> "收到。你是电池工艺工程师，成长期，电子科大(985)毕业，最看重薪资和天花板。
> 电池对口行业簇：锂电池/钠电池/固态电池/燃料电池/光伏/储能。
> 国家级集群：常州碳材料、宜宾遂宁锂电、宁德锂电新能源、长三角新能源汽车。
> 电子科大在成都，校友网络对成渝地区是加分项。开始评估候选城市。"

## Step 3: 候选城市确定

> 以下搜索预计耗时 3-5 分钟，7 个维度并行搜索数据量较大，请耐心等待。

### 情况A：用户指定了城市

直接对指定城市做 7 维评估（通常 2-5 个城市）。

### 情况B：用户指定了城市群

```
城市群选项：
- 长三角（上海/苏州/杭州/南京/宁波/无锡/常州/合肥）
- 珠三角（深圳/广州/东莞/佛山/珠海/惠州）
- 成渝（成都/重庆/绵阳/宜宾）
- 京津冀（北京/天津/石家庄/保定/唐山）
- 中部（武汉/长沙/郑州/南昌/太原）
- 其他：山东半岛/海峡西岸/东北
```

先对各城市群做宏观对比（产业生态/薪资水平/生活成本/政策力度），输出城市群排名 → 用户选 1-2 个 → 群内城市详细 7 维评估。

### 情况C：还没想好

```
你想怎么扫？
A. 聚焦核心（15-20个城市）— 省会+计划单列市+产业强市，覆盖面广且快
B. 全面扫描（30+城市）    — 含所有二线，能发现冷门选择，耗时较长
C. 先选区域再细扫         — 先告诉我想去哪片（长三角/珠三角/...），再在区域内扫
```

- 选 A → 从职业行业簇反推产业集聚城市列表（约15-20个），直接进入 7 维评估
- 选 B → 扩大候选池到 30+，每个维度搜索深度适当降低
- 选 C → 转情况B的流程

## Step 4: 7维度并行搜索

Read `references/data-sources.md` 获取数据源详情。

### 核心原则

1. **7维度并行**：产业 + 薪酬 + 天花板 + 成长 + 政策 + 生活 + 城市群
2. **信号驱动**：每维度 2-3 个搜索变体，捕获权威信号即可打分
3. **Agent 并行派发**：7个维度用 Agent 同时搜索

### 搜索执行清单

| # | 维度 | 搜索内容 | 数据工具 | 完成 |
|---|------|---------|---------|:---:|
| 1 | 产业匹配度 | 国家级产业集群标签、专精特新密度、招聘岗位数 | WebSearch + mcp-cnbs | ☐ |
| 2 | 薪酬性价比 | 行业薪资 / (房价收入比 × 生活成本) | WebSearch + mcp-cnbs | ☐ |
| 3 | 职业天花板 | 行业龙头数、独角兽密度、人才净流入率 | WebSearch + Exa | ☐ |
| 4 | 成长土壤 | 高校、实验室、技术社区、校友网络 | WebSearch | ☐ |
| 5 | 人才政策 | 落户门槛、购房/租房补贴、人才公寓 | WebSearch | ☐ |
| 6 | 生活适配 | 气候、通勤、医疗、教育、方言 | WebSearch | ☐ |
| 7 | 城市群生态 | 产业链跨城配套、城际交通便利度 | WebSearch | ☐ |

### 搜索模板

#### 第 1 路：产业匹配度
```
"[城市] 国家级先进制造业集群 [行业关键词]"
"[城市] 专精特新 小巨人 数量"
"[城市] [搜索关键词] 招聘 岗位"
```
通过 mcp-cnbs 补充：`cnbs_compare("工业增加值", [城市列表], "city")`

#### 第 2 路：薪酬性价比
```
"[城市] [职业] 薪资 2025 2026"
"[城市] 租金 一居室 2025 2026 月租"
"[城市] 房价收入比 2025"
"[城市] 房租收入比 租房负担 2025"
```

薪酬性价比 = 租房负担率得分 × 阶段权重 + 购房负担率得分 × 阶段权重
详见 `references/city-scoring-model.md` 维度2。

#### 第 3 路：职业天花板
```
"[城市] 独角兽 2025 2026 [行业]"
"[城市] 上市公司 总部 [行业]"
"[城市] 人才净流入 2025"
```

#### 第 4 路：成长土壤
```
"[城市] 双一流 高校 [对口专业]"
"[城市] 国家重点实验室 [行业]"
"[城市] 技术社区 开发者"
"[学校名] 校友 [城市]" (如果有学校信息)
```

#### 第 5 路：人才政策
```
"[城市] 人才引进 补贴 2025 2026"
"[城市] 落户政策 应届生"
"[城市] 人才公寓 [学校层次关键词]"
"[城市] 人才补贴 兑现 落实 2025"
```

#### 第 6 路：生活适配
```
"[城市] 通勤时间 45分钟 比重 2025"
"[城市] 房租 生活成本 气候"
"[城市] 三甲医院 数量"
"[城市] 方言 文化 包容性"
```

#### 第 7 路：城市群生态
```
"[城市群] 产业链 跨城配套 [行业]"
"[城市] 到 [群内核心城市] 高铁"
"[城市群] 十四五 产业协同"
```

## Step 5: 加权打分

Read `references/city-scoring-model.md` 获取完整评分细则。

### 打分流程

1. 对每个候选城市，在每个维度上根据搜索信号打出 1-10 分
2. 根据用户阶段选择默认权重矩阵
3. 根据用户偏好（Step 1 问题四）调整权重并重新归一化
4. 应用校友网络加分（如有学校信息）
5. 应用减分项（人口流出、行业裁员、政策失信等）
6. 计算加权总分并分层

### 分阶段默认权重速查

| 维度 | 应届(0-3年) | 成长期(3-6年) | 定居(6年+) |
|------|:------:|:------:|:------:|
| 产业匹配度 | 25% | 20% | 15% |
| 薪酬性价比 | 20% | 25% | 20% |
| 职业天花板 | 20% | 20% | 15% |
| 成长土壤(含校友) | 15% | 10% | 5% |
| 人才政策 | 5% | 10% | 15% |
| 生活适配 | 5% | 10% | 20% |
| 城市群生态 | 10% | 5% | 10% |

### 分层展示

| 总分 | 层级 | 展示方式 |
|------|------|------|
| ≥ 7.5 | 强烈推荐 | 默认展开，置顶，7维度详细拆解 |
| 5.5-7.4 | 值得考虑 | 默认展开，表格对比 |
| 3.5-5.4 | 备选 | `<details>` 折叠 |
| < 3.5 | 不推荐 | 不展示（除非用户指定） |

## Step 6: 输出报告

Read `references/advisor-template.md` 获取完整模板。

### 输出结构

1. **推荐摘要**（200字以内）— 首推城市 + 核心理由
2. **强烈推荐城市** — 7维度表格拆解 + 学校因素标注
3. **值得考虑城市** — 维度得分表格对比
4. **备选城市** — `<details>` 折叠
5. **城市群宏观对比**（如适用）
6. **尾部引导** — "选定城市后，用 company-screener 看具体公司"

## 边界情况

### 学校信息缺失
跳过校友网络加分和学校层次加分，在报告开头标注"未提供学校信息，校友网络维度为中性"。

### 职业未在映射表中
从职业名称提取关键词，使用通用行业簇，标注"该职业不在预设映射表中，产业匹配为通用评估"。

### 候选城市过多（>20个）
每个维度搜索深度适当降低（每个维度搜 2 轮而非 3 轮），"值得考虑"层每个城市只输出总分+一句话，不展开维度。

### 候选城市过少（<3个）
如果只评估 1-2 个城市，输出改为"目标城市适配度评估"格式，不做排名对比，而是逐维度分析适合度和风险点。

### 完全搜不到信号
诚实告知，标注数据源局限。城市信号稀疏本身就是一条信息（该城市可能不适合此职业）。

### 用户选了"还没定方向"
先问感兴趣的行业，没有则使用通用行业簇。标注"职业未明确，推荐为通用产业视角"。

## 质量规则

1. 每条信号标注来源类型和年份
2. 薪资数据标注年份和来源平台（不同平台数据差异大）
3. 人才政策标注年份（政策可能已调整）
4. 学校层次加分规则透明，在报告中列明
5. 分值可追溯（哪条信号加了几分）
6. 查不到就说查不到，不编造数据
7. 城市推荐不是命运判决——是信息聚合后的结构化讨论起点
