# 输出模板

career-path 报告的输出结构和格式规范。X=枚举的方向总数，Y=高度匹配数，Z=值得探索数。

---

## 报告结构

```
1. IKIGAI 自画像（200字）
2. 方向总览表格
3. 高度匹配方向详细展开（1-3个）
4. 值得探索方向表格
5. 可做备选方向折叠
5. 转行路径图（如有）
6. 尾部引导
```

---

## 1. IKIGAI 自画像

模板：
```
## 你的 IKIGAI 自画像

        热爱: [兴趣标签1, 兴趣标签2]
         /            \
        /   交集:        \
       /   [1-2个方向]    \
  擅长: [能力标签] —————— 被需要: [市场标签]
              \
               \
           有报酬: [薪资偏好]

你的偏好类型偏向 RIASEC 中的 **[X型]**（[一句话解释]）。

**交集区域**：[方向A] 落在热爱+擅长+被需要的三圈交集，值得重点看。

**盲区提醒**：[缺失圈] 较弱，意味着 [风险]，建议 [应对策略]。
```

## 2. 方向总览

模板：
```
## 方向总览（共 X 个方向）

| # | 方向 | 层级 | 入门门槛 | 起薪 | 天花板 | 匹配度 | 推荐 |
|---|------|------|:--:|:------:|:------:|:--:|:--:|
| 1 | 机械结构设计 | 直接对口 | 低 | 8-12万 | 25-40万 | 100% | ★★★ |
| 2 | CAE仿真工程师 | 直接对口 | 中 | 10-18万 | 30-50万 | 95% | ★★★ |
| ... | ... | ... | ... | ... | ... | ... | ... |
```

匹配度 = career-path-map.md 中的预设匹配度 × 个人适配调整（来自 IKIGAI 匹配分）

## 3. 三个方向深度展开

不按分数排名，而是输出**三个有意义的差异化选项**：
- 稳妥之选：匹配度高 + 门槛适中 + 岗位多
- 高回报之选：天花板高 + 增长快 + 风险也大
- 你没想过的：IKIGAI标签匹配 + 但不在你的自选列表里

生成规则详见 `references/path-scoring-model.md` 的"三选项生成规则"。

每个选项一页：

```
## 最终推荐：三个值得深入的方向

你的IKIGAI标签: 兴趣([标签]) + 能力([标签])
Cross Off: [排除项/无]

### 1. 稳妥之选 — [方向名]（X.X分）

匹配度高 + 确定性最强。

[2-3句话说明为什么是稳妥之选：引用入行可行性+市场趋势+兴趣匹配的关键数据]

| 维度 | 得分 | 说明 |
|------|:--:|------|
| 入行可行性 | X/10 | [理由 + 数据来源] |
| 薪资成长性 | X/10 | 起薪 X万 → 天花板 Z万 [[来源]] |
| 市场趋势 | X/10 | [增长/平稳 + AI替代判断] [[来源]] |
| 兴趣匹配 | X/10 | 你的 [兴趣标签] 与该方向 [工作环节] 吻合 |
| 能力匹配 | X/10 | 你的 [能力标签] 与该方向 [核心技能] 重叠 |

**入行路径**：[第一步 → 第二步 → 第三步，3-4句话说清楚]
**主要城市**：[城市列表]
**风险提示**：[一句话]

### 2. 高回报之选 — [方向名]（X.X分）

[同上格式，强调天花板+增速+风险]

### 3. 你没想过的 — [方向名]

不在你的自选列表里，但IKIGAI标签（[标签]）指向它。

[同上格式，强调为什么标签匹配 + 为什么你可能没想过]

---

**其余方向**（折叠）

<details>
<summary>另外 X 个方向 — 点击展开</summary>

| # | 方向 | 总分 | 类型 | 一句话 |
|---|------|:--:|------|------|
| 4 | ... | X.X | 值得探索 | ... |
| 5 | ... | X.X | 可做备选 | ... |

</details>
```

## 4. 转行路径图（如有）

仅在用户需要转行时输出：

```
## 转行路径: [当前方向] → [目标方向]

### 技能桥
[当前方向技能] ──重叠──→ [目标方向技能]
[当前方向技能] ──需补充──→ [缺失技能]（自学 X 个月）

### 推荐路径
[当前岗位] → [中间跳板岗位]（X 年）→ [目标岗位]

### 具体第一步
[本周可以做的具体行动，如：在B站搜XX课程 / 注册XX平台 / 联系XX人]
```

## 7. 尾部引导

```
---
**下一步：**
- 确定方向后 → 用 `city-advisor` 看哪个城市最适合这个方向
- 选定城市后 → 用 `company-screener` 发现该城市的好公司
- 拿到面试/offer → 用 `company-research` 做深度背调

还想深入了解哪个方向？
```

---

## 格式规范

1. 所有薪资数据标注年份和来源，如 `[BOSS直聘·2026]`
2. 推断类判断标注 `[推断]`
3. 方向名称使用加粗，与 career-path-map.md 一致
4. 报告总长度控制在 300 行以内（不含折叠内容）
5. 摘要优先：IKIGAI 自画像在前，详细展开在后
