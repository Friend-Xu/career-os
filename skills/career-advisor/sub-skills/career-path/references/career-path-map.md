# 专业→职业方向 索引

career-path 独立维护版。面向职业方向选择，结构：直接对口 → 可迁移 → 跨界方向。

---

## 使用方式

1. 读本索引 → 匹配用户专业到对应文件
2. Read 对应 directions/*.md（每个 ~100-140 行，含完整方向表+画像卡）
3. 展示方向总览表 → 用户初筛感兴趣的 3-5 个
4. 对用户感兴趣的方向，在 Step 4 并行搜索获取实时市场数据
5. 专业不在表中 → 使用底部"通用搜索簇"

## 通用搜索簇（专业不在表中时使用）

当用户专业不在预设 8 类中时，从专业名称提取关键词，使用以下通用框架：

```
层级推理:
  1. 直接对口: 专业名称本身就是岗位名（如"会计"→会计/审计）
  2. 可迁移: 专业中的通用能力能做什么（如"数学"→数据分析/金融/算法）
  3. 跨界: 完全不相关但可入门的方向（如"历史"→互联网运营/产品）

搜索关键词: "[专业名] 就业方向" + "[专业名] 转行"
```

## RIASEC 兴趣类型速查

用于 Step 3 IKIGAI 四问中帮用户理解自己的偏好类型：

| 类型 | 标签 | 典型偏好 | 适配方向示例 |
|:----:|------|------|------|
| **R** | 现实型 | 动手操作、工具机器、户外 | 机械设计、设备工程师、施工管理 |
| **I** | 研究型 | 分析、推理、解决抽象问题 | CAE仿真、算法、药物研发 |
| **A** | 艺术型 | 创造、表达、非结构化 | UI/UX设计、内容策划、自媒体 |
| **S** | 社会型 | 帮助他人、教学、人际 | 教师、HR、医药代表、咨询 |
| **E** | 企业型 | 领导、说服、竞争、目标导向 | 销售、产品经理、创业 |
| **C** | 常规型 | 流程、规则、数据、精确 | 审计、财务、质量工程师、RA |

**使用方式**：IKIGAI 四问后，根据用户回答映射到 1-2 个 RIASEC 类型，作为"你可能属于 X 型"的参考标签，不做评分输入。
