# career-path — 职业路径规划

求职决策链的最上游：帮你在同一个专业/背景下，看清所有可能的职业方向，找到最适合自己的那一条。

## 与其它 skill 的关系

```
career-path (本 skill)      →  "我该做什么方向？"
city-advisor                →  "我该去哪个城市？"
company-screener            →  "这个城市有什么好公司？"
company-research            →  "这家公司值不值得去？"
```

## 使用方式

直接在 Claude Code 中说：
- "机械专业能做什么方向"
- "CAE工程师和机械设计怎么选"
- "转行怎么做，我是土木的想转互联网"
- "帮我规划一下职业方向"
