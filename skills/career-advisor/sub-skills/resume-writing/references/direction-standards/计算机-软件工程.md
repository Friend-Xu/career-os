- **按投递岗位收主线**：投 iOS 岗就把 Swift/SwiftUI/iOS 性能优化写重；投 Android 岗就把 Kotlin/Jetpack Compose/内存优化写重；投跨平台岗就突出 Flutter/React Native
- **每项目 3-5 bullet**，关键技术关键词按 JD 要求排序，无关方向果断舍弃
- **筛选**：选 2-3 个最出彩项目，每个项目标注 `平台：XX｜技术栈：XX｜角色：XX`

## 通用：软件工程全方向量化动词速查表

| 弱动词 | → 方向定制表述 |
|--------|-------------|
| 负责 | 主导 / 独立完成 / 牵头设计 |
| 参与 | 完成[子模块/子系统]的架构设计与落地 |
| 做了 | 实现 / 构建 / 交付 / 从 0 到 1 搭建 |
| 用了 | 基于 [技术栈] 设计/实现 [方案]，解决 [问题] |
| 优化了 | 将 [指标] 从 A 优化至 B / 通过 [手段] 提升 X% |
| 重构了 | 主导 [系统/模块] 从 [旧架构] 向 [新架构] 的演进 |
| 改了 | 通过 [技术方案] 修复/改进 [问题] |
| 提升了 | 将 [指标] 从 [A] 提升至 [B]，增幅 X% |
| 降低了 | 将 [指标/Cost] 从 [A] 压降至 [B]，降幅 X% |

| 解决了 | 根因分析 [问题]，通过 [方案] 闭环，[影响] |
