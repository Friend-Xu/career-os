## 一、机械结构设计

### HR 高频搜索关键词
SolidWorks、AutoCAD、Creo、UG/NX、CATIA、ANSYS、有限元分析、BOM、工程图、
公差分析、GD&T、DFM/DFA、DFMEA、材料选型、钣金、机加工、压铸、焊接、注塑、
样机调试、结构方案、尺寸链、传动设计、电机选型、标准件选型（米思米/怡合达）

### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 减重 | "通过拓扑优化减重 X% / Ykg" | 结构优化、轻量化 |
| 成本 | "单台成本降低 X 元 / BOM 成本压缩 X%" | 降本 |
| 寿命 | "疲劳寿命从 X 次提升至 X 次" | 可靠性改进 |
| 精度 | "重复定位精度 ±Xmm" | 精密机构 |
| 图纸量 | "独立完成 X 张+ 工程图 / X 套 BOM" | 设计产出 |
| 项目周期 | "X 个月内完成从方案到 SOP 全流程" | 项目交付 |

### 行内强力动词
| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 负责设计 → 独立完成 XX 的结构方案与详细设计 | 主导项目 |
| 参与了 → 负责[子模块]的结构设计与出图 | 明确子项 |
| 改了 → 优化/迭代了 XX 结构 | 改进设计 |
| 画图 → 完成 XX 的三维建模与二维工程图 | 具体动作 |
| 选了 → 完成 XX 的标准件/材料选型与校核 | 选型 |
| 仿真了 → 基于 ANSYS 完成 XX 的静力学/模态分析 | CAE |

### 项目分组惯例
- **命名**：`[产品名/系统名] — [阶段/任务]`，如"C2900 生化分析仪 — 核心结构校核"
- **组织**：按产品线（生化/发光/酶标），或按技术方向（传动/结构/热管理）
- **每项目 2-4 bullet**，按 STAR 拼接

### ATS 关键词清单
SolidWorks, AutoCAD, Creo, Pro/E, UG/NX, CATIA, ANSYS, Abaqus, HyperWorks,
GD&T, DFM, DFA, FMEA, BOM, SOP, APQP, PPAP, ISO 9001, IATF 16949

网格划分、二次开发（Tosca/Isight 优化）

### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 减重 | "拓扑优化实现减重 X%，通过强度验证" | 结构优化 |
| 精度 | "仿真与试验误差控制在 X% 以内" | 对标验证 |
| 效率 | "收敛时间缩短 X%" | 仿真流程 |
| 应力 | "关键件最大应力降低 X%" | 结构改进 |
| 温度 | "最高温度降低 XK / 散热效率提升 X%" | 热管理 |
| 网格 | "完成百万级网格的 XX 模型划分" | 复杂模型 |
| 项目 | "完成 X 类产品的全流程仿真分析与优化" | 经验 |

### 行内强力动词
| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 分析了 → 基于 Abaqus/Standard 完成 XX 非线性接触分析 | 具体仿真 |

| 优化了 → 通过拓扑优化/参数化扫描将 XX 减重 X% | 优化 |
| 验证了 → 完成仿真与试验对标，误差 X% | 验证 |

### 项目分组惯例

- **组织**：按分析类型（结构/流体/热/多物理场）或产品分组
- **每项目 2-4 bullet**，强调工具→方法→结果→验证全链条

### ATS 关键词清单

## 通用：机械全方向量化动词速查

|--------|-------------|
| 负责 | 主导 / 独立完成 / 全程负责 |
| 参与 | 完成[子模块]的设计与出图 |
| 做了 | 实现 / 优化 / 交付 / 落地 |
| 画图 | 完成 XX 的三维建模与二维工程图 |
| 选了 | 完成 XX 的标准件/材料选型与校核计算 |
