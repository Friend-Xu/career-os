### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 性能提升 | "抗拉强度从 X MPa 提升至 Y MPa / 提升 X%" | 力学性能优化 |
| 良率 | "主导配方优化，产品良率从 X% 提升至 Y%" | 工艺改善 |
| 成本 | "通过材料替代/国产化，年度节省 X 万元" | 降本 |
| 实验量 | "独立完成 X 组+ SEM/XRD/DSC 表征与数据分析" | 实验产出 |
| 成果 | "申请发明专利 X 项（已授权 Y 项）/ 发表 SCI 论文 X 篇" | 学术产出 |
| 转化 | "完成从实验室 X g 级到中试 X kg 级的工艺放大" | 中试放大 |
| 效率 | "测试周期从 X 天缩短至 Y 天" | 流程优化 |

### 行内强力动词
| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 负责研发 → 主导 XX 材料从配方设计到中试验证的全流程开发 | 全流程 |
| 做了实验 → 设计 X 组 DOE 实验，系统考察 A/B/C 因素对 XX 性能的影响 | 实验设计 |
| 测了 → 基于 XRD/SEM/DSC 完成 XX 材料的物相/形貌/热学表征 | 表征 |
| 优化了 → 通过工艺参数优化（温度/时间/配比），将 XX 性能提升 X% | 参数优化 |
| 分析了 → 根因分析定位 XX 失效模式，提出改进方案并验证闭环 | 失效分析 |

| 转化了 → 完成 XX 材料从实验室到中试产线的工艺转化与验证 | 量产 |
| 选型了 → 完成 XX 应用场景下的材料选型与性能校核 | 选型 |

### 项目分组惯例
- **命名**：`[材料体系] — [核心问题/性能目标]`，如"长循环硅碳负极材料 — 界面调控与失效机理"、或 `[项目来源] [研究内容]`，如"国家自然科学基金 — 高熵合金强韧化机制"
- **组织**：按材料体系（高分子/金属/无机非金属/复合材料）或按研究阶段（基础研究 → 应用开发 → 中试转化），也可按问题导向（配方优化 / 失效分析 / 工艺放大）
- **每项目 2-4 bullet**，遵循"背景-机理-工艺-性能-成果"五段式
