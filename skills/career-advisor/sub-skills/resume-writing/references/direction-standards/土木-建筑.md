## 一、结构设计工程师

### HR 高频搜索关键词
PKPM、YJK（盈建科）、AutoCAD、MIDAS Gen、SAP2000、ETABS、ANSYS、ABAQUS、
Revit、Tekla、3D3S、STAAD.Pro、TSSD、有限元分析、抗震设计、混凝土结构、
钢结构、装配式建筑、BIM 协同设计、施工图绘制、超限审查、
结构方案优化、注册结构工程师、框架-核心筒、大跨度结构、地基基础

### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 材料节省 | "优化梁柱截面，节省钢材用量 X% / X 吨" | 结构优化、降本 |
| 成本降低 | "通过结构方案比选，降低造价 X 万元 / X%" | 方案优化 |
| 项目规模 | "负责 X 万㎡ 商业综合体 / 超高层（Xm）结构设计" | 项目量级 |
| 工期 | "施工图出图效率提升 X%，提前 X 天交付" | 设计效率 |
| 图纸量 | "独立完成 X 张+ 结构施工图，一次通过审图" | 设计产出 |
| 审查通过 | "主导 X 个项目超限审查，一次性通过率 X%" | 技术难度 |
| 重量优化 | "通过拓扑优化减重 X%，承载力提升 X%" | 结构优化 |
| 抗震性能 | "罕遇地震下弹塑性层间位移角满足 1/XX 限值" | 抗震设计 |

### 行内强力动词
| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 负责设计 → 独立完成 XX 的结构方案确定与施工图设计 | 主导项目 |
| 参与了 → 负责 [子项/楼层/构件] 的结构计算与出图 | 明确子项 |
| 改了 → 优化/迭代了 XX 结构方案 | 改进设计 |
| 算了 → 基于 YJK/PKPM 完成 XX 结构内力分析与配筋计算 | 计算分析 |
| 画图 → 完成 XX 的结构施工图绘制及图纸校审 | 制图 |
| 仿真了 → 基于 ABAQUS/ANSYS 完成 XX 节点非线性有限元分析 | CAE |
| 配合 → 与建筑/设备专业协同，解决 XXX 处专业碰撞 | 跨专业 |

### 项目分组惯例
- **命名**：`[项目名称]（X 万㎡，XX 结构体系）| 结构设计师/专业负责人`，如"XX 国际广场（35 万㎡，框筒超高层）| 结构专业负责人"
- **组织**：按项目类型（商业综合体/住宅/工业厂房/公共建筑），或按结构体系（混凝土/钢结构/混合结构），时间倒序
- **每项目 3-4 bullet**，按 STAR 拼接：背景规模 → 你的角色 → 关键技术动作 → 量化成果

| 负责 | 主导 / 独立完成 / 全周期管控 / 全程负责 |
| 参与 | 完成 [子项/标段/专业] 的 [设计/施工/建模] |
| 做了 | 实现 / 优化 / 交付 / 落地 / 闭环处理 |
| 画图/建模 | 完成 XX 的结构施工图绘制 / XX 全专业 LOD350 模型搭建 |
| 算了 | 基于 [PKPM/YJK/MIDAS] 完成 XX [内力/配筋/抗震] 计算 |
| 管进度 | 编制三级/四级进度计划，每日跟踪纠偏、关键路径优化 |
| 管质量 | 专项检查 X 次、发现缺陷 X 处、督促闭环整改 |
| 管安全 | 编制安全预案、巡检排查 X 次、隐患整改率 100% |
