## 通用：经管全方向量化动词速查

| 弱动词 | → 方向定制表述 |
|--------|-------------|
| 负责 | 主导 / 操盘 / 独立完成 / 全程统筹 |
| 参与 | 深度参与[子模块]，独立完成[具体交付物] |
| 做了 | 策划并执行 / 设计并落地 / 推动并上线 |
| 优化了 | 通过[方法/工具]将[指标]从A优化至B（±Z%） |
| 分析了 | 基于[工具/方法]完成XX分析，输出X份报告并推动策略调整 |
| 协调了 | 牵头[跨部门/跨团队]协作，对齐目标并推动按期高质量交付 |
| 写了 | 独立撰写PRD/审计报告/品牌策略方案/培训体系方案，通过评审 |
| 增长了 | 通过[策略/机制]驱动[核心指标]从X增长至Y（+Z%） |
| 降低了 | 将[风险/成本/流失率/周期]从X降至Y（-Z%），通过[手段] |
| 搭建了 | 从0到1搭建[体系/流程/机制]，覆盖X团队/X部门/X城市 |
| 发现了 | 通过[审计程序/数据分析/用户调研]识别[风险/机会/痛点]X项 |
| 验证了 | 通过A/B测试/对标分析/仿真验证，确认[假设/方案]有效性 |
