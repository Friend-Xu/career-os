## 一、内容运营/新媒体编辑

### HR 高频搜索关键词
微信公众号、小红书运营、抖音、视频号、知乎、微博、选题策划、爆款内容、
文案撰写、短视频脚本、剪辑（剪映/PR）、排版（秀米/135编辑器）、数据分析、
用户增长、粉丝互动、私域引流、社群运营、KOL/KOC合作、活动策划、
热点追踪、矩阵运营、转化率、阅读量、AIGC 工具应用、全媒体运营

### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 阅读量/播放量 | "单篇最高阅读量 XX 万 / 月均阅读量从 X 万提升至 Y 万" | 公众号、内容平台 |
| 粉丝增长 | "3 个月内粉丝从 X 增长至 Y（增长率 Z%）" | 账号运营 |
| 互动率 | "推文平均打开率从 X% 提升至 Y%（超行业均值 Z%）" | 内容质量 |
| 爆款产出 | "产出 X 篇 10w+ 爆款 / 爆款率 Y%" | 内容能力 |
| 转化率 | "内容引流转化率 X% / 单场直播 GMV X 万元" | 商业价值 |
| 矩阵规模 | "搭建 X 个垂直账号矩阵，总粉丝 Y 万" | 规模化运营 |
| 内容产出量 | "月均产出原创推文 X 篇 / 累计输出短视频脚本 X 条" | 产能 |
| 活动数据 | "策划线上活动覆盖 X 万用户，参与率 Y%" | 活动运营 |
| 效率提升 | "建立 SOP 体系使内容产出周期缩短 X%" | 流程优化 |

### 行内强力动词
| 通用动词 --> 方向定制 | 使用场景 |
|-------------------|---------|
| 负责公众号 --> 独立运营 XX 领域公众号（0-->1 启动），月均产出原创 X 篇 | 主导账号 |
| 写文案 --> 策划并撰写 XX 选题系列，单篇打开率超行业均值 X% | 内容创作 |
| 做视频 --> 主导短视频矩阵建设，完成脚本撰写+拍摄+剪辑全流程 | 视频制作 |
| 搞活动 --> 策划并执行 XX 话题活动，联动 X+ KOL 铺稿 | 活动策划 |
| 看数据 --> 基于平台数据复盘，优化选题策略与推送节奏 | 数据分析 |
| 涨粉了 --> 通过内容优化与用户分层运营，X 个月内粉丝增长 Y% | 增长 |
| 带团队 --> 统筹 X 人内容团队，建立选题日历与质量 SOP | 管理 |
| 追热点 --> 借势 XX 热点完成品牌内容植入，48h 内产出并推送 | 热点响应 |

### 项目分组惯例
- **命名**：`[平台/产品] -- [阶段/策略]`，如"XX 品牌公众号 -- 0-->1 冷启动" 或 "XX 话题小红书矩阵 -- 种草转化"
- **组织**：按平台（公众号/小红书/抖音/视频号）或按内容类型（图文/短视频/直播/IP 孵化）
- **每项目 2-4 bullet**，按 STAR 拼接，核心数据（阅读量/涨粉/转化）必须在第一句
- **零经验者**可用个人自媒体账号运营经历替代，如 `个人小红书账号 -- 0-->X 万粉`

### ATS 关键词清单
微信公众号, 小红书, 抖音, 视频号, 知乎, 微博, B站, 剪映, Premiere(PR), Photoshop(PS),
Canva, 秀米, 135编辑器, 稿定设计, Excel(数据透视表/VLOOKUP), 千瓜, 新榜, Google Analytics,
SQL(加分), CRM, 企业微信, 飞书, SOP, CTR, ROI, GMV, UGC, SEO, SEM, CET-4/6, 全媒体运营师(认证)

## 二、翻译/本地化

### HR 高频搜索关键词
CATTI 二级/一级、英语专八 TEM-8、Trados、MemoQ、笔译、口译、审校、
本地化、术语管理、翻译记忆库、译后编辑、语言对（中英/中日/中法）、
日产出量、质量保证 QA、交替传译、同声传译、技术文档翻译、游戏本地化、
法律翻译、医疗翻译、字幕翻译、多语言项目管理、跨文化沟通

### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 翻译量 | "累计中英笔译 X 万字 / 年翻译量 X 万字" | 经验证明 |
| 日产出 | "日均产出 X 字/词 / 日翻译量 3000-4000 英文词" | 产能证明 |
| 错误率 | "译稿错误率控制在 X% 以下 / 一次性通过率 X%" | 质量 |
| 效率 | "通过 Trados 术语库使项目交付效率提升 X%" | 工具价值 |
| 客户满意度 | "客户返工率下降 X% / 满意度 X 分" | 服务质量 |
| 术语库 | "建立含 X 条术语的 XX 领域术语库" | 资产积累 |
| 项目数量 | "成功交付 X 个本地化项目，涉及 Y 个语种" | 项目经验 |
| 成本节省 | "通过翻译记忆库复用，项目成本降低 X%" | 商业价值 |
| 速度 | "翻译速度 X 字/小时 / 交付周期缩短 X%" | 效率 |

### 行内强力动词
| 通用动词 --> 方向定制 | 使用场景 |
|-------------------|---------|
| 负责翻译 --> 独立完成 XX 领域（技术/法律/游戏）XX 万字笔译 | 领域翻译 |
| 做了审校 --> 完成 XX 万字译稿审校，建立 QA 规范，错误率降至 X% | 质量把控 |
| 参与项目 --> 主导 XX 本地化项目全流程（术语提取-->译后编辑-->交付） | 项目管理 |
| 用 Trados --> 基于 Trados Studio 搭建 XX 领域翻译记忆库与术语库 | 工具深度 |
| 做字幕 --> 使用 Aegisub 完成 XX 剧集字幕翻译与时间轴适配 | 字幕翻译 |
| 口译了 --> 完成 XX 场商务谈判/会议交替传译，零重大失误 | 口译 |
| 整理了 --> 编制 XX 领域风格指南与术语规范，覆盖 X 语种 | 规范建设 |
| 协调了 --> 统筹 X 人译员团队，管理多语种并行交付 | 管理 |

### 项目分组惯例
- **命名**：`[领域] [项目/产品名] -- [角色]`，如"游戏本地化《XX》-- 中英翻译与 LQA" 或 "法律翻译 -- 跨国并购协议系列"
- **组织**：按领域分类（游戏/法律/医疗/科技/金融/市场），或按服务类型（笔译/口译/本地化/审校）
- **每项目 2-4 bullet**，必须包含：语言对 + 字数 + 领域 + 工具 + 成果
- **格式建议**：项目经验表格化展示（项目名/语言对/字数/领域/时间）更受翻译公司 HR 青睐

### ATS 关键词清单
CATTI(一级/二级/三级笔译/口译), TEM-8(专八), TEM-4(专四), IELTS(7.0+), TOEFL(100+),
BEC 高级, 上海高级口译, NAATI, DALF(C1/C2), JLPT N1, Trados Studio, MemoQ,
Phrase(Memsource), YiCAT, Transmate, Xbench, Aegisub, Audacity, Deja Vu,
SDL, 翻译记忆库, 术语管理, 译后编辑, LQA, QA, 笔译, 口译, 同声传译, 交替传译,
本地化(Localization), 字幕翻译, 游戏本地化, 技术文档, ISO 17100, ISO 9001

## 三、教育培训（语言类）

### HR 高频搜索关键词
教师资格证、专八 TEM-8、雅思 IELTS（7.0+/7.5+）、托福 TOEFL（100+）、
TESOL、TEFL、CELTA、TKT、普通话等级（二甲/一乙）、全英文授课、
国际课程（IB/A-Level/AP/IGCSE）、课程设计、教研、班级管理、家校沟通、
课堂控场、分层教学、CLIL 教学法、形成性评估、线上教学平台、
学生满意度、续课率、试听课转化

### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 教学量 | "累计授课 X 课时 / X 年 XX 学科教学经验" | 教学经验 |
| 成绩提升 | "班级平均分从 X 提升至 Y / 及格率从 X% 升至 Y%" | 教学效果 |
| 通过率 | "X 名学生通过 YLE/KET/PET / A 率 X% / 高考 120 分+占比 X%" | 考级/升学 |
| 续课率 | "学员续课率达 X% / 留存率提升 X 个百分点" | 商业价值 |
| 满意度 | "家长满意度 X 分（满分 5）/ NPS 净推荐值 X" | 服务质量 |
| 课件产出 | "独立开发 X 套课程 / 设计 Y 份教案 / 建立含 Z 份教案的分级档案库" | 教研产出 |
| 试听转化 | "试听课转化率从 X% 提升至 Y%" | 招生能力 |
| 竞赛指导 | "指导学生获 XX 竞赛 X 等奖 / X 名学生获奖" | 竞赛成果 |
| 班级规模 | "同时负责 X 个班级 / Y 名学生教学与管理" | 管理能力 |

### 行内强力动词
| 通用动词 --> 方向定制 | 使用场景 |
|-------------------|---------|
| 负责教学 --> 独立教授 IGSCE/IB/A-Level XX 课程，全英文授课 X 课时/周 | 学科教学 |
| 备课了 --> 基于 CEFR 标准设计课程大纲，累计编写 X 份教案 | 课程设计 |
| 提高了成绩 --> 通过分层教学与课后一对一辅导，班级均分从 X 提升至 Y | 教学成果 |
| 管班级 --> 管理 X 人班级，建立正面行为支持体系，课堂参与度提升 Y% | 班级管理 |
| 沟通家长 --> 建立每周学情反馈机制，家长满意度达 X 分 | 家校沟通 |
| 研发课程 --> 主导 XX 校本课程从 0 到 1 开发，被 Y 位教师采用 | 教研 |
| 培训老师 --> 组织 X 场教研分享会，培训 Y 名新教师 | 团队赋能 |
| 做了活动 --> 设计并实施英语角/演讲辩论活动，学生口语流利度提升 X% | 课外拓展 |

### 项目分组惯例
- **命名**：`[课程/项目名称] -- [阶段/角色]`，如"IGCSE ESL 课程教学 -- 主授课教师" 或 "XX 校本课程开发项目 -- 项目负责人"
- **组织**：按课程体系（IB/A-Level/AP/国内课程）或按教学模块（课堂教学/教研开发/竞赛指导/班级管理）
- **每项目 2-4 bullet**，核心成果数据（成绩提升/满意度/课时量）前置
- **项目与经历区分**：教研/课程开发类放在"项目经历"，日常教学放在"工作经历"；教学成果可单列"教学成果"模块

教师资格证(标注学科+学段+年份), TEM-8(专八), TEM-4(专四), IELTS(7.0+/7.5+),
TOEFL(100+), TESOL, TEFL, CELTA, TKT, 普通话(二甲/一乙), IB, A-Level, AP,
IGCSE, CLIL, CEFR, ClassIn, Zoom, Google Classroom, Canvas, Nearpod, Kahoot,
Quizlet, 希沃白板, Smart Board, Microsoft Teams for Education, IEP, 分层教学,
全英文授课, 形成性评估, 课程设计, 教研, 班级管理, 家校沟通
