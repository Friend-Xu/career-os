## 一、制药工艺工程师

### HR 高频搜索关键词
GMP、cGMP、工艺验证（PV）、清洁验证（CV）、工艺放大/中试放大、技术转移、
SOP、偏差调查、CAPA、变更控制、工艺优化、DOE、HPLC、GC、Minitab、
CAD/AutoCAD、批生产记录、固体制剂/无菌制剂、注册申报（CTD/CMC）、
无菌灌装、细胞培养/发酵、纯化、ICH Q7/Q8/Q10、FDA、NMPA、OOS/OOT

### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 收率 | "通过DOE优化反应参数，收率从 X% 提升至 Y%" | 工艺优化 |
| 效率 | "工艺优化使单批生产周期缩短 X% / 产能提升 X%" | 效率提升 |
| 偏差 | "主导 X 起关键偏差调查，闭环率 X%，同类偏差减少 X%" | 质量事件 |
| 成本 | "推动 XX 替代方案，单批成本降低 X 万元 / 年节省 X 万元" | 降本 |
| 文件量 | "编制/升版 SOP X+ 份，批记录 X+ 套，覆盖 X 条产线" | 文件体系 |
| 技术转移 | "主导 X 个品种从研发到 GMP 车间的技术转移，3 批验证全部通过" | 转移 |
| 验证 | "完成 X 次工艺验证（PV）/清洁验证（CV），一次通过率 X%" | 验证 |
| 产能 | "工艺放大实现规模放大 X 倍，车间月产能从 X 提升至 Y" | 放大 |

### 行内强力动词
| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 负责工艺 → 主导 XX 品种从研发到商业化的全工艺开发 | 全流程 |
| 优化了 → 通过 DOE 优化 XX 工艺参数，收率从 X% 提升至 Y% | 参数优化 |
| 放大了 → 完成 XX 产品从实验室到中试/GMP 车间的工艺放大与表征 | 放大 |
| 转移了 → 主导 XX 品种向 YY 基地的技术转移，完成差距分析与风险评估 | 技术转移 |
| 验证了 → 编制 XX 工艺验证方案并组织跨部门实施，一次通过 | 验证 |
| 调查了 → 根因分析定位 XX 偏差，制定 CAPA 并推动闭环 | 偏差处理 |
| 编制了 → 独立完成 XX 产品工艺规程、批生产记录及 SOP 体系搭建 | 文件体系 |
| 降本了 → 通过 XX 工艺改进/物料替代，年度节省 Y 万元 | 降本 |

### 项目分组惯例
- **命名**：`[产品/品种] — [阶段/任务]`，如"XX 原料药 — 工艺放大与验证"、"XX 注射液 — 无菌灌装工艺优化"
- **组织**：按品种/剂型（原料药/固体制剂/无菌制剂/生物制剂）或项目类型（工艺开发/技术转移/验证/降本）
- **每项目 2-4 bullet**，强调 GMP 关键词、工艺数据、个人主导角色

| 通用动词 → 方向定制 | 使用场景 |

### 项目分组惯例

## 三、临床研究 CRA/CRC

> CRA（临床监查员）与 CRC（临床研究协调员）有清晰的职责边界，但共享大量共通关键词。
> 简历撰写需根据目标岗位（监查方 vs 站点方）调整动词侧重和数据维度。

### CRA 子方向

#### HR 高频搜索关键词
ICH-GCP、SDV（源数据核查）、监查访视（SIV/IMV/RMV/COV）、EDC、方案偏离（PD）、
SAE/AE 报告、中心管理、TMF/eTMF、ISF、Query 管理/数据清理、入组进度、CRC 协调、
知情同意（ICF）、稽查准备、风险导向监查（RBM）、CAPA、Medidata Rave、CTMS、
II/III 期、肿瘤/心血管/免疫、CRO、申办方、NMPA/FDA/EMA

#### 量化指标锚点
| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 中心数 | "独立负责 X 家研究中心的全流程监查" | 项目规模 |
| 访视量 | "完成监查访视 X 次（含 SIV Y 次/COV Z 次），SDV 完成率 X%" | 工作量 |
| 入组 | "推动 X 家滞后中心入组达标，整体入组提前 Y 天完成" | 进度 |
| Query | "Query 按时关闭率 X%，平均关闭周期缩短 Y%" | 数据质量 |
| 偏离 | "发现并整改 X 例方案偏离，降低后续偏离率 Y%" | 质量 |
| 稽查 | "主导 X 家中心稽查准备，稽查中无重大发现（No Major Finding）" | 合规 |
| 周期 | "将中心启动周期从 X 周缩短至 Y 周" | 效率 |
| 表扬 | "获申办方/项目组书面表扬 X 次" | 认可 |

#### 行内强力动词
| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 负责监查 → 独立管理 X 家研究中心，完成全流程监查访视 | 中心管理 |
| 核查了 → 完成 X 次源数据核查（SDV），发现并整改 Y 例方案偏离 | SDV |
| 推动了 → 推动 X 家中心入组进度，提前 Y 天完成入组目标 | 进度管理 |
| 协调了 → 协调 CRC/研究医生/伦理委员会，解决 X 项中心瓶颈问题 | 协调 |
| 关闭了 → 完成 X 家中心关闭访视（COV），所有文档完整归档 | 关中心 |
| 准备了 → 主导 X 家中心 NMPA 核查/申办方稽查准备，零重大发现 | 稽查 |
| 优化了 → 建立数据溯源核查清单，Query 率降低 X% | 流程优化 |
| 培训了 → 完成 X 家中心 SIV，培训研究者/CRC Y 人次 | 启动 |

#### 项目分组惯例
- **命名**：`[治疗领域] [试验分期] — [角色]`，如"非小细胞肺癌 III 期 — 项目 CRA"、"糖尿病 II 期 — Lead CRA"
- **组织**：按治疗领域（肿瘤>心血管>免疫>内分泌）或试验分期（III 期优先）排序
- **每项目 2-4 bullet**，核心要素：适应症+分期+中心数+核心行动（SIV/SDV/入组/稽查）+量化成果
- 英文缩写（SDV/SIV/COV）首次出现时标注全称

#### ATS 关键词清单
ICH-GCP, GCP, SDV, SDR, SIV, IMV, RMV, COV, EDC, eCRF, CTMS, eTMF, IWRS,
Medidata Rave, Oracle Clinical, Oracle InForm, Veeva Vault, REDCap,
SAE/AE, 方案偏离（PD）, CAPA, Query Resolution, ICF（知情同意）,
TMF, ISF, IRB/EC, RBM（基于风险的监查）, ALCOA, CDISC,
NMPA, FDA 21 CFR Part 11, HIPAA, GDPR,
Phase I/II/III/IV, 肿瘤, 心血管, CRO, 申办方
