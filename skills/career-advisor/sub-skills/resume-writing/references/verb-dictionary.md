# 动词词典

弱动词 → 强动词映射。按行为类型分组。遵循"不做假"原则——只在用户真实行为范围内替换。

---

## 使用规则

1. **同义替换** — 用更精确/更有力的动词描述同一行为，不改变行为本身
2. **场景匹配** — 同一个弱动词在不同场景下映射到不同的强动词，选最贴合的
3. **保留口语风格** — 不要太书面化或翻译腔
4. **不堆砌** — 一个 bullet 用 1-2 个强动词就够了

---

## 一、统筹类

"负责/承担/主要做" 的升级：

| 弱动词 | 场景 | → 强动词 |
|--------|------|---------|
| 负责 | 从零开始建了某件事 | 搭建、建立、组建 |
| 负责 | 主导推进了某个方向 | 主导、统筹、主持 |
| 负责 | 管某件事的日常运行 | 管理与维护、运作 |
| 负责 | 带领团队完成某件事 | 带领、率领 |
| 负责 | 建立规章制度类 | 制定、建立 |
| 负责 | 承担某块业务的责任 | 承担、担当、扛起 |
| 承担 | 同上 | 担当、扛起、背负 |
| 主要做 | 同上 | 聚焦、主攻、专攻 |

## 二、执行类

"做了/参与/协助/完成" 的升级：

| 弱动词 | 场景 | → 强动词 |
|--------|------|---------|
| 做了 | 把某件事从头做到尾 | 完成、交付、落地 |
| 做了 | 把某件事做得比以前好 | 优化、提升、改进 |
| 做了 | 从多个方案中选了最优的 | 筛选、甄选、选定 |
| 参与 | 参与了某模块/子任务 | 负责[子项]、完成[模块] |
| 参与 | 配合别人推进整体项目 | 配合[人]完成、协同[团队]推进 |
| 协助 | 给某项工作提供支持 | 协助[人]完成、支撑、保障 |
| 帮助 | 帮别人解决问题 | 协助[人]解决、扶持 |
| 完成 | 达到预定目标 | 达成、实现 |
| 完成 | 按时按质交付 | 如期交付、保质交付 |
| 执行 | 按计划执行 | 推进、实施、贯彻、落实 |

## 三、创造类

"写/想/设计/做新的" 的升级：

| 弱动词 | 场景 | → 强动词 |
|--------|------|---------|
| 写 | 写文档/方案/报告 | 撰写、编写、输出 |
| 写 | 写技术规范/标准 | 编制、制定 |
| 写 | 写专利/论文 | 发表、申请 |
| 写 | 写代码 | 开发、编写、实现 |
| 想 | 想方案/策略 | 设计、规划、制定 |
| 想 | 从零构思 | 构思、创造、开创 |
| 设计 | 设计产品/系统 | 设计、开发、创建、构建 |
| 设计 | 设计流程/制度 | 制定、建立、规划 |
| 做新的 | 从0到1 | 开创、开辟、首创 |
| 做新的 | 引入新技术/方法 | 引进、导入、推行 |

## 四、协作类

"协调/沟通/对接" 的升级：

| 弱动词 | 场景 | → 强动词 |
|--------|------|---------|
| 协调 | 协调部门之间 | 拉通[部门A+部门B]、跨部门协同 |
| 协调 | 协调外部资源 | 对接、打通、引入 |
| 协调 | 推动多方达成共识 | 推动、促成、撮合 |
| 沟通 | 向上级汇报 | 汇报、同步、对齐 |
| 沟通 | 做了客户/用户访谈 | 访谈、调研、采集 |
| 沟通 | 和客户谈需求和方案 | 对接、洽谈、磋商 |
| 对接 | 对接供应商/外部 | 谈判、议价、筛选 |
| 对接 | 对接上下游 | 打通、衔接、串联 |

## 五、分析类

"分析/看/检查" 的升级：

| 弱动词 | 场景 | → 强动词 |
|--------|------|---------|
| 分析 | 分析数据 | 挖掘、洞察、剖析 |
| 分析 | 分析竞品 | 对标、对比、摸底 |
| 分析 | 分析根因 | 诊断、定位、排查 |
| 检查 | 质量检查 | 检验、检测、验证 |
| 检查 | 审核/审查 | 审计、复核、核对 |
| 看 | 看趋势/变化 | 监测、跟踪、追踪 |
| 了解 | 调研学习 | 研究、调研、摸底 |

## 六、改善类

"优化/改进/提升" 的升级：

| 弱动词 | 场景 | → 强动词 |
|--------|------|---------|
| 优化 | 优化流程 | 精简、再造、重构 |
| 优化 | 优化性能 | 提速、调优、压缩 |
| 优化 | 优化成本 | 节省、压缩、砍掉 |
| 改进 | 改进工艺/方法 | 改善、革新、迭代 |
| 提升 | 提升数据指标 | 拉升、拔高、突破 |
| 提升 | 提升团队能力 | 赋能、激活、锤炼 |
| 解决 | 解决问题 | 攻克、排除、化解 |
| 解决 | 解决突发状况 | 应急、救火、化险 |

## 七、管理类

"带人/培养/管理" 的升级：

| 弱动词 | 场景 | → 强动词 |
|--------|------|---------|
| 带人 | 带新人/实习生 | 指导、带教、培养 |
| 带人 | 带团队 | 带领、统率、管理 |
| 管团队 | 日常管理 | 管理与维护、主持日常工作 |
| 管团队 | 有编制和考核权 | 直接管理（N人团队，含绩效评定） |
| 培训 | 主动培训别人 | 讲授、传授、赋能 |
| 培训 | 编写培训材料 | 编制培训大纲、撰写SOP |
| 审核 | 审别人的工作 | 审阅、核定、审批 |

## 速查索引

按用户口述中的弱动词快速定位映射：

```
负责 → 统筹类          做了 → 执行类 / 创造类
参与 → 执行类          协助 → 执行类
写   → 创造类          想   → 创造类
设计 → 创造类          协调 → 协作类
沟通 → 协作类          对接 → 协作类
分析 → 分析类          检查 → 分析类
优化 → 改善类          改进 → 改善类
提升 → 改善类          解决 → 改善类
带人 → 管理类          管团队 → 管理类
培训 → 管理类          审核 → 管理类
```
