## 量化指标锚点

| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 减重 | "通过拓扑优化减重 X% / Ykg" | 结构优化、轻量化 |
| 成本 | "单台成本降低 X 元 / BOM 成本压缩 X%" | 降本 |
| 寿命 | "疲劳寿命从 X 次提升至 X 次" | 可靠性改进 |
| 精度 | "重复定位精度 ±Xmm" | 精密机构 |
| 图纸量 | "独立完成 X 张+ 工程图 / X 套 BOM" | 设计产出 |
| 项目周期 | "X 个月内完成从方案到 SOP 全流程" | 项目交付 |
| 性能 | "一阶固有频率从 X Hz 提升至 Y Hz" / "最大应力降低 X%" | 结构优化（调研补充） |
| 机器人 | "关节重量降低 X% / 扭矩密度提升 X%" | 机器人结构（调研补充） |
| 产品经验（医械） | "主导 X 款二类/三类有源设备整机结构设计" | 产品 |
| 注册（医械） | "完成 NMPA/FDA/CE 注册文档中结构设计部分的编写" | 合规 |
| 验证（医械） | "完成 X 项设计验证测试，通过率 X%" | 测试 |
| 量产（医械） | "推动 X 款产品从样机到量产，月产能 X 台" | 量产 |
| 成本（医械） | "在符合 ISO 13485 前提下，BOM 成本降低 X%" | 降本 |

## 行内强力动词

| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 负责设计 → 独立完成 XX 的结构方案与详细设计 | 主导项目 |
| 参与了 → 负责[子模块]的结构设计与出图 | 明确子项 |
| 改了 → 优化/迭代了 XX 结构 | 改进设计 |
| 画图 → 完成 XX 的三维建模与二维工程图 | 具体动作 |
| 选了 → 完成 XX 的标准件/材料选型与校核 | 选型 |
| 仿真了 → 基于 ANSYS 完成 XX 的静力学/模态分析 | CAE |
| 负责设计（医械） → 独立完成 XX（二类/三类）器械整机结构设计与 DHF 文档 | 主导 |
| 做了测试（医械） → 主导 XX 器械的设计验证与设计确认 | 验证 |
| 配合注册（医械） → 配合完成 XX 产品的 NMPA 注册结构部分文档 | 合规 |
| 选了材料（医械） → 完成医用级 XX 材料选型，满足生物相容性要求 | 材料 |
| 跟了开模（医械） → 主导 XX 注塑件开模评审与试模验证 | 模具 |

## 项目分组惯例

- **命名**：`[产品名/系统名] — [阶段/任务]`，如"C2900 生化分析仪 — 核心结构校核"
- **组织**：按产品线（生化/发光/酶标），或按技术方向（传动/结构/热管理）；医械按注册分类（生化/发光/酶标/血球）
- **每项目 2-4 bullet**，按 STAR 拼接；医械法规关键词（ISO 13485、DHF、NMPA）至少出现在一个项目中
- 机器人岗位按关节系统/本体/末端执行器分组（调研补充）
