## 量化指标锚点

| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 减重 | "拓扑优化实现减重 X%，通过强度验证" | 结构优化 |
| 精度 | "仿真与试验误差控制在 X% 以内" | 对标验证 |
| 效率 | "收敛时间缩短 X%" | 仿真流程 |
| 应力 | "关键件最大应力降低 X%" | 结构改进 |
| 温度 | "最高温度降低 XK / 散热效率提升 X%" | 热管理 |
| 网格 | "完成百万级网格的 XX 模型划分" | 复杂模型 |
| 项目 | "完成 X 类产品的全流程仿真分析与优化" | 经验 |
| 温升（热） | "整机温升从 X℃ 降至 Y℃，满足降频阈值" | 热管理（调研补充） |
| 热阻（热） | "接触热阻降低 X%（更换导热界面材料）" | 热管理（调研补充） |

## 行内强力动词

| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 分析了 → 基于 Abaqus/Standard 完成 XX 非线性接触分析 | 具体仿真 |
| 建了模型 → 完成 XX 六面体主导网格划分与边界条件设定 | 前处理 |
| 优化了 → 通过拓扑优化/参数化扫描将 XX 减重 X% | 优化 |
| 验证了 → 完成仿真与试验对标，误差 X% | 验证 |
| 写了 → 编制 XX 产品仿真分析规范/SOP | 规范 |
| 开发了 → 基于 Python 完成 XX 仿真后处理自动化脚本 | 二次开发 |
| 仿了热（热） → 基于 FloTHERM 完成 XX 系统级/板级稳态与瞬态热仿真 | 热仿真（调研补充） |
| 选了散热（热） → 完成 XX 散热方案选型（风冷/液冷/VC）并仿真验证 | 散热选型（调研补充） |
| 算了流（流体） → 基于 Fluent 完成 XX 流道流场与压损仿真分析 | CFD（调研补充） |

## 项目分组惯例

- **命名**：`[产品/系统] [分析类型] — [工具]`，如"涡轮叶片 流-热-固耦合 — ANSYS"
- **组织**：按分析类型（结构/流体/热/多物理场）或产品分组
- **每项目 2-4 bullet**，强调工具→方法→结果→验证全链条；仿真类项目必须包含对标或验证动作（调研补充）
