## 量化指标锚点

| 锚点类型 | 示例表述 | 适用场景 |
|---------|---------|---------|
| 交付量 | "独立交付 X 台套非标设备" | 项目经验 |
| 节拍 | "产线节拍从 X 秒缩短至 Y 秒" | 效率 |
| 成本 | "单台设备成本降低 X 万元" | 降本 |
| 良率 | "设备运行良率从 X% 提升至 Y%" | 质量 |
| 设计效率 | "方案设计周期缩短 X%" | 标准化 |
| 项目规模 | "主导 X 万元级自动化产线方案设计与交付" | 量级 |
| OEE | "设备 OEE 从 X% 提升至 Y%（目标 ≥85%）" | 设备运行（调研补充） |
| 停机 | "非计划停机时间降低 X%" | 设备维护（调研补充） |
| 交付 | "按期交付率 X% / X 条产线按期验收" | 产线集成（调研补充） |
| UPH | "产线 UPH 从 X 提升至 Y" | 产线集成（调研补充） |

## 行内强力动词

| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 负责 → 独立主导 XX 自动化产线方案设计与交付 | 整线 |
| 设计了 → 完成 XX 设备的整机三维建模与零部件拆分 | 整机 |
| 选了 → 完成 XX 气动/伺服/传动系统选型计算 | 选型 |
| 调试了 → 现场完成 XX 设备装配调试与精度验证 | 交付 |
| 优化了 → 将 XX 工位节拍从 X 秒优化至 Y 秒 | 节拍 |
| 修了（设备） → 主导 XX 设备故障根因分析（5Why/FTA）并制定预防措施 | 故障处理（调研补充） |
| 维护了（设备） → 建立 XX 产线 TPM 点检保养体系，覆盖 X 台设备 | 维护体系（调研补充） |
| 联调了（集成） → 主导 XX 产线整线机械联调与精度验证，按期通过验收 | 整线集成（调研补充） |

## 项目分组惯例

- **命名**：`[行业] [设备类型] — [客户/产线]`，如"3C 电子自动锁螺丝机 — XX 产线"
- **组织**：按行业（3C/锂电/汽配）或设备类型（装配线/检测机/包装线）
- **每项目 2-4 bullet**；集成类按系统（上下料/输送/视觉/控制）或项目阶段（方案/集成/验收）分组（调研补充）
