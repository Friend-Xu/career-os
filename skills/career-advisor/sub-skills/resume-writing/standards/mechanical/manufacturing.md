## 行内强力动词

| 通用动词 → 方向定制 | 使用场景 |
|-------------------|---------|
| 负责工艺 → 主导 XX 产品从试产到量产的全制程开发 | 全流程 |
| 优化了 → 通过 DOE 优化 XX 参数，良率从 X% 提升至 Y% | 参数优化 |
| 解决了 → 根因分析定位 XX 异常，制定改善对策并闭环 | 异常处理 |
| 编了 SOP → 编制 XX 工序 SOP 及标准工时，覆盖 X 条产线 | 标准化 |
| 降本了 → 推动 XX 工装/材料国产化，年节省 X 万元 | 降本 |
| 编程了（机加） → 完成 XX 零件 CAM 编程与切削参数优化 | 机加（调研补充） |
| 调参了（注塑） → 主导 XX 产品注塑参数调试，解决 XX 缺陷 | 注塑（调研补充） |
| 试模了（注塑） → 主导 XX 模具试模与验收，输出试模报告 | 注塑（调研补充） |
| 防错了（装配） → 设计 XX 工序防错方案，降低装配错误率 X% | 装配（调研补充） |
| 平衡了（装配） → 完成 XX 产线线平衡优化，消除 X 个瓶颈工序 | 装配（调研补充） |

## 项目分组惯例

- **命名**：`[产品/产线] — [制程阶段/问题]`，如"XX 产品注塑制程 — 良率提升"
- **组织**：按产品线或制程类型（注塑/机加工/焊接/装配）
- **每项目 2-4 bullet**；制程改善项目按"问题 → 根因 → 对策 → 验证"闭环组织（调研补充）
