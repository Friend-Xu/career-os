# 面试准备指南

从 JD 分析结果生成：预测问题 + 反问清单 + 风险应对。

---

## 一、问题预测

### 1.1 生成规则

每条 JD 要求 → 1-2 个面试问题。

```
维度1: JD要求类型       → 问题类型
维度2: JD动词           → 问题深度和角度
维度3: 候选人弱项       → 追问/压力问题
```

### 1.2 问题类型映射

| JD要求类型 | 问题类型 | 示例模板 |
|-----------|---------|---------|
| 硬技能/工具 | 技术深度题 | "你用过 [工具] 做的最复杂的 [任务] 是什么？" |
| 软技能 | 行为面试题（STAR） | "描述一次你 [软技能] 的经历" |
| 职责描述 | 场景假设题 | "如果让你 [JD职责]，你会怎么推进？" |
| 行业经验 | 行业认知题 | "你怎么看 [行业] 当前的变化对 [岗位] 的影响？" |
| 管理/领导力 | 管理场景题 | "你管理过的最大团队是？遇到最难管的成员怎么处理？" |

### 1.3 动词 → 问题角度

| 动词 | 问题角度 |
|------|---------|
| 搭建/创建/从0到1 | "你从零搭建过什么？过程中最大的困难是什么？" |
| 优化/提升/改善 | "你优化过什么指标？用什么方法？提升了多少？" |
| 主导/牵头 | "你主导过最大的项目是？怎么推动不配合的人？" |
| 维护/保障 | "你处理过最紧急的线上故障/生产问题是什么？" |

### 1.4 弱项 → 压力问题

候选人某JD要求技能为"△ 部分匹配"或"✗ 缺失"时，生成1个针对该弱项的压力问题：

> "我看到你的经历里[弱项]经验主要是[当前水平]。这个岗位需要[JD要求]，你觉得你需要多长时间能上手？"

## 二、面试官分层

| 面试官 | 关注点 | 会问什么 | 你该反问什么 |
|--------|--------|---------|------------|
| HR（初面） | 基本匹配、动机、薪资预期 | "为什么离开现在的工作？为什么投我们？" | 流程、制度、入职评估标准 |
| 直属领导 | 能力深度、上手速度、团队协作 | 技术深挖 + 项目经验 + 工作习惯 | 团队状态、目标期望、管理风格 |
| 高管/合伙人 | 战略视野、业务理解、成长潜力 | 行业认知 + 大局观 + 价值观 | 战略方向、资源投入、长期规划 |
| 跨部门/同级 | 协作能力、沟通风格 | 协作场景 + 冲突处理 | 协作模式、团队间关系 |

## 三、反问生成（Pivot Theory 方法）

### 核心原则

**不问"会不会……"（答案永远是会），问"上次……是什么时候"（问过去行为和具体数据）。**

| 无效问法 | 有效问法 |
|---------|---------|
| "这个岗位有成长空间吗？" | "过去一年团队里有人晋升吗？" |
| "团队会加班吗？" | "团队最近一次赶项目是什么时候？持续了多久？" |
| "技术栈先进吗？" | "最近一个项目中用了什么技术？为什么选它？" |

### 从 JD 推导反问

```
JD模糊处 → 具体化反问
  例：JD写"良好的团队氛围" →
    "团队有什么固定的团建或分享机制？最近一次是什么？"

JD缺失处 → 探查反问
  例：JD没提团队规模 →
    "岗位所在团队现在多少人？未来半年计划扩到多少？"
  例：JD没提前任 →
    "这个岗位是新设还是替代？如果是替代，前任做了多久、为什么离开？"

JD风险信号 → 验证反问
  例：JD写"抗压能力强" →
    "团队最近一次高压项目是什么情况？持续了多久？"
  例：JD写"弹性工作制" →
    "团队的日常工作时间是怎样的？有没有核心工作时间段？"
```

### 面试官分层反问

```
对HR：
  - "新人的试用期评估标准是什么？"
  - "过去一年这个岗位招过吗？上任为什么离开？"
  - "公司对这个岗位的晋升路径是怎样的？"

对直属领导：
  - "你希望这个人在头三个月解决什么问题？"
  - "团队目前最大的技术挑战/业务瓶颈是什么？"
  - "你的管理风格是怎样的？你希望团队成员的沟通方式是什么？"

对高管：
  - "公司在[业务方向]的投入规划是怎样的？"
  - "你评判这个岗位'远超预期'的标准是什么？"
  - "公司未来一年的最大不确定性是什么？"
```

## 四、故事线准备

### STAR 故事库

为 JD 分析出的每个 Critical 和 Important 要求准备 1 个 STAR 故事：

```
## 故事 #1: [对应JD要求]
S: [背景 — 2句话]
T: [我的任务 — 1句话]
A: [关键行动 — 3-5条，动词开头]
R: [结果 — 必须量化]
Trade-off: [取舍/失败/学到什么]

追问备答（5个）：
  1. [数据归因逻辑？]
  2. [scope边界？]
  3. [为什么不选替代方案？]
  4. [成本/时间换了吗？]
  5. [重来一次怎么做？]
```

### 2分钟自我介绍

```
1. 我的背景: "[专业/当前岗位]，做了[X年][核心领域]"
2. 我为什么投: "[一句话说清动机]"
3. 我能做什么: "[1个最有说服力的故事概括核心能力]"
4. 我想得到什么: "[跟岗位成长空间对应]"

示例（机械设计→机器人）：
  "我是机械工程专业，做了1.8年汽车零部件结构设计。
   在设计过程中我对机构的运动学和动力学越来越感兴趣，
   花了一年系统学习机器人相关基础，并做了一个6轴机械臂Demo。
   我投贵司是因为[产品]对传动链设计的要求
   跟我的机械背景和运动学兴趣高度匹配。
   我希望在这个岗位上把结构设计能力迁移到'能动的机械'上。"
```

## 五、风险应对

### 弱项回应

```
弱项: [技能] — 当前水平 vs JD要求
  A. 已有计划在补 → "目前在[具体行动]，预计[X周/月]达到[水平]"
  B. 有可迁移能力 → "没用过[A]，但用[B]做过类似的事，原理相通"
  C. 岗位不一定需要 → Nice-to-have不提，被问到再回应
```

### Gap 应对

如有 career-transition 检测到的 gap：

> "那[X个月/年]我用来 [系统学习了XX/确定了职业方向/做了XX探索]。
>  这段经历让我确认了 [关键认知]，
>  这也是我今天坐在这里投 [目标方向] 而不是 [原方向] 的原因。"

### 薪资谈判参考

```
薪资参考:
  JD范围: [min]-[max]
  行业同岗位同经验: [推断·范围]
  公司薪资在行业中的位置: [从company-research推断 or 标注不确定]

谈判要点:
  - JD上限低于市场价 → "JD薪资偏低，面试时试探是否可谈"
  - 转行首份 → "转行首份薪资可能略低于同行，但不应低于JD下限"
  - 公司有期权 → "B轮及以前公司期权是重要组成部分，需确认兑现条件"
```

## 六、输出示例

```
## 面试准备包：机器人本体设计工程师 @ [公司名]

### 预测问题（高优先级，准备STAR故事）

技术面：
  1. "你做过最复杂的传动机构设计是什么？从选型到验证的流程？"
  2. "你对谐波减速器和RV减速器的理解？适用场景和失效模式？"
  3. "你在设计中用过运动学分析吗？用什么方法验证设计？"

行为面：
  4. "你现在的公司流程比较完善（汽车Tier1），创业公司节奏不同，怎么适应？"

### 反问建议

必须问：
  ⊙ "这个岗位是新增还是替代？如果是替代，前任为什么离开？"
  ⊙ "团队现在多少机械设计？主打产品对本体设计的最大技术挑战？"

建议问：
  ○ "自研装配线，机械设计团队参与哪些环节？"

### 风险应对

弱项: ROS经验不足（JD要求"了解"）
  回应: "做机器人Demo项目时接触了ROS基础。如需要，1-2周可上手。"
  储备: ROS官网Tutorial已完成前5章。

弱项: 无机器人行业经验
  回应: "是的，我没有机器人行业的直接经验。但我在汽车Tier1做的
        精密运动机构设计——齿轮传动、公差控制、DFM——
        和机器人本体设计核心能力相通。一年系统学习+Demo项目，
        让我不是零基础转行。"
```
