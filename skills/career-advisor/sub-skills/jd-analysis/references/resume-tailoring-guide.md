# 简历定制指南

将 JD 分析结果转化为具体的简历修改指令。不编造经历，只重新组织和翻译。

---

## 一、核心原则

1. **只重新组织，不编造** — 改写基于候选人已有的真实经历
2. **用 JD 的语言说话** — 同样的事实，用 JD 中的术语描述
3. **证据可追溯** — 每条改写都能对应到原始经历
4. **弱项诚实标注** — "学习中"不伪装成"精通"

---

## 二、四级定制深度

| 级别 | 耗时 | 内容 | 适用场景 |
|:--:|:--:|------|------|
| L1 关键词优化 | 5-10分钟 | 技能区注入JD关键词、动词替换 | 匹配度≥70%，同方向投递 |
| L2 选择性改写 | 15-20分钟 | L1 + 个人总结改写 + 3-5条经历bullet重构 | 匹配度50-70% |
| L3 战略重组 | 20-30分钟 | L2 + 经历顺序调整 + 分区重组 + 弱项应对 | 匹配度40-60%，转行 |
| L4 完整重写 | 45-60分钟 | L3 + 每一条bullet重写 + 全文语言统一 | 匹配度<40%但决定投 |

---

## 三、结构化改写指令

### 3.1 个人总结改写

```
公式：[身份] + [核心能力(JD关键词)] + [职业意向]

原始："机械设计工程师，2年经验，熟悉SolidWorks"

改写（投机器人岗）：
"机械设计背景，2年精密结构设计和传动机构开发经验，
 系统学习过机器人运动学和动力学基础，寻求机器人本体设计岗位。"

JD关键词映射：
  "精密结构设计" ← "做过零件设计"
  "传动机构开发" ← "做过齿轮/轴承选型"
  "运动学" ← gap期间考研学习的内容
```

### 3.2 经历顺序调整

```
原则：与JD最相关的经历放在最前面

- 创建"相关经历"分区（置顶）
- 相关工作经历给5-7条bullet
- 不相关经历归入"其他经历"，给2-3条bullet
- 转行者：Demo项目/自学项目可放在工作经历之前
```

### 3.3 技能分区重组

```
- JD提到的技能 → 置顶并标记熟练度
- JD未提到但候选人精通 → 保留但后置
- 与目标方向完全无关 → 可删除
- "不想再用"的技能 → 不出现
```

### 3.4 Bullet 改写模式

#### L1 动词替换

```
"负责XX" → "主导XX"（如果确实主导）
"参与了YY" → "完成了YY[模块]"（如果确实完成）
"协助同事做ZZ" → "配合团队完成ZZ"

规则：用强动词替换弱动词，但必须在真实范围内
```

#### L2 STAR 重构

```
原始："负责用户增长，DAU提升20%"

STAR重构：
  S: "面对竞品补贴战和预算砍半"
  T: "被要求不增加投放预算的前提下维持增长"
  A: "设计了老带新裂变模型，重构了push触达策略"
  R: "0成本实现DAU环比增长30%，同时跑通了会员转化新路径"

最终bullet："面对预算砍半+竞品补贴双重压力，设计裂变增长模型替代付费投放，
          实现DAU环比增长30%（0新增成本），同时验证了会员付费转化路径。"
```

#### L3 JD 语言翻译（转行者最常用）

```
原始: "用SolidWorks完成汽车零部件的3D建模和工程图出图"

JD语言翻译（投机器人岗）：
  "负责精密运动机构的3D结构设计和公差分析，
   出图符合IATF 16949体系要求"

翻译要点：
  - "汽车零部件" → "精密运动机构"（JD语言重新描述）
  - "3D建模" → "3D结构设计和公差分析"（JD中提到公差分析）
  - 加了"IATF 16949" → 质量体系经验可迁移
```

## 四、ATS 关键词优化

### 注入位置（按ATS权重排序）

1. 个人总结（权重最高）
2. 最近一份工作的前3条bullet
3. 技能区
4. 职位名称

### 注入规则

- JD核心硬技能词 → 自然融入个人总结和经历bullet
- 每段经历中自然出现1-2个关键词即可
- 核心技能词重复率控制在2-3%
- 使用JD原文措辞（"客户拓展"不要改成"客户开发"）

### 格式兼容

- 单栏布局（不用表格、文本框）
- 字体：宋体或微软雅黑，11-12pt
- 不超过3种颜色
- 文件命名：姓名-岗位-学校-经验年限.pdf
- 长度：<5年经验=1页，5-10年=最多2页

## 五、诚实边界

### 不可跨越

```
✗ 编造没做过的项目
✗ "参与"改成"主导"
✗ 编造量化数据（"提升30%"如果无数据支撑）
✗ 声称没有的证书
✗ "听说过"改成"熟练掌握"
✗ 编造经历填补gap
```

### 可以做的

```
✓ 用JD的术语重新描述真实经历
✓ 从真实经历中挖掘被忽略的量化结果
✓ 重新组织顺序，突出匹配部分
✓ 弱项标注为"学习中"
✓ 在真实范围内使用强动词替换弱动词
✓ gap包装为"方向探索期"（如果确实做了探索）
```

### 弱项应对

```
弱项: SQL复杂查询经验不足
  A. 写过简单查询 → "熟练SQL日常数据提取，正在深入学习窗口函数"
  B. 只学过课程 → "系统学习过SQL（含join/subquery），有课程项目实践"
  C. 完全不会 → 不写，不硬凑
```

## 六、输出格式

以**改写指令清单**而非新简历全文输出：

```
## 简历定制指令：[当前岗位] → [目标岗位] @ [公司名]

### 定制深度：L2 选择性改写（预计20分钟）

### 1. 个人总结 → 替换为：
"[新版本]"

### 2. 技能区 → 调整：
  置顶：[JD要求技能]
  后置：[无关但精通]
  删除：[不想再用的]

### 3. 经历 #1 → Bullet改写：
  原文：[...]
  改写："[强动词] + [方法] + [结果]"
  证据来源：[简历·第X段]

### 4. 关键词注入：
  - [keyword] → 个人总结 + 经历#1

### 5. 弱项应对：
  - [弱项] → [策略]
```
