## 使用说明

### 在 JD 质量评估中使用

阶段1 扫描 JD 文本，命中的黑话按严重度扣分：
- **高严重度** → -2 分
- **中严重度** → -1 分
- **低严重度** → 0 分（标注但不扣分）

### 在 JD 深度拆解中使用

阶段2 将命中的黑话归入"隐性信号"或"红旗标注"：

```
隐性信号示例：
  "弹性工作制" → [文化信号] 大概率无加班费且随时待命
  "团队年轻有活力" → [团队信号] 平均经验不足，缺乏导师

红旗标注示例：
  "狼性文化" → 末位淘汰+强制加班 — 高风险
  "薪资面议" → 大概率低于行业平均 — 中风险
```

### 未覆盖信号的处理

当 JD 中出现本词典未收录的可疑措辞时，按以下规则判断：

1. 措辞**模糊、回避具体信息** → 该维度信息缺失，标注不确定性
2. 措辞**过于正面、夸大** → 真实性存疑，降低该公司的信息可信度
3. 措辞**暗示边界模糊**（"一家人"、"共同成长"） → 大概率工作生活边界差
4. 措辞**强调态度而非能力**（"有激情"、"有干劲"） → 可能工作量大、薪资低
