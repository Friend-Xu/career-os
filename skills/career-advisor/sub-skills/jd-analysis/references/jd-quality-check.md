# JD 质量评估

判断一个 JD 是否值得深度分析。五轴评分 + 欺诈检测 + 平台适配。

---

## 一、评估流程

```
JD 文本输入
    ↓
平台识别（BOSS直聘/猎聘/拉勾/51job/智联/通用）
    ↓
轴5: 欺诈检测 → 触发 → SKIP（不可覆盖）
    ↓ 未触发
轴1-4: 综合评分 → 汇总 → PASS / WARN / SKIP
```

---

## 二、轴1：JD清晰度（权重25%）

### 正向信号

| 信号 | 分值 |
|------|:--:|
| 具体提到团队名称、产品线、技术栈 | +2 |
| 有可衡量的30/60/90天成功标准 | +2 |
| 职责描述具体（有场景、有指标、有工具名） | +1 |
| 明确标注"新增岗位"或"替代岗位" | +1 |

### 负向信号

| 信号 | 分值 |
|------|:--:|
| 标题用"大神/大牛/Guru/Ninja"等花名 | -2 |
| 5种以上不相关职能杂糅（运营+设计+开发+客服） | -2 |
| 通用描述，能套到10个团队上 | -2 |
| 47条以上要求 | -2 |
| "身兼多职"/"多面手" | -2 |
| "其他领导交办的任务"占比过高 | -1 |
| "没有两天是相同的" | -1 |
| 职责描述全部用"负责"开头且无具体内容 | -1 |

## 三、轴2：薪资透明度（权重15%）

### 正向信号

| 信号 | 分值 |
|------|:--:|
| 明确薪资范围且与市场水平一致 | +2 |
| 详细列出福利（公积金比例、年终奖结构等） | +1 |

### 负向信号

| 信号 | 分值 |
|------|:--:|
| "薪资面议" | -2 |
| 范围跨度>2倍（如10K-30K） | -2 |
| "上不封顶"（=下不保底） | -2 |
| "五险一金齐全"作为首要福利卖点 | -1 |
| "有竞争力的薪酬"但无数字 | -1 |
| "Base+期权" | -1 |
| "年底有奖金"但未说明基数或计算方式 | -1 |

## 四、轴3：文化与工作量信号（权重20%）

> 完整黑话词典见 `euphemism-dictionary.md`。

**高严重度（每个 -2）**：抗压能力强、弹性工作制、狼性文化、大家庭/我们是一家人、包三餐/免费晚餐/报销打车、不提倡/不强制加班、双休被作为卖点、以公司为家

**中严重度（每个 -1）**：扁平化管理、团队年轻有活力、工作有激情/有强烈责任心、拥抱变化、结果导向、快节奏/适应较快的工作节奏、有创业心态

**正向信号（+1）**：JD明确提到"不加班文化"、"965"、"双休保证"等

无文化信号：0 分

## 五、轴4：招聘行为（权重20%）

### 正向信号

| 信号 | 分值 |
|------|:--:|
| 岗位在公司官网可查 | +2 |
| 公司近期有融资/扩张新闻 | +1 |
| LinkedIn上有员工发文提到团队扩张 | +1 |

### 负向信号

| 信号 | 分值 |
|------|:--:|
| 同一岗位每2-4周重发一次、持续6个月+ | -2 |
| 岗位在第三方平台有但公司官网没有 | -2 |
| "急聘"+"立即到岗"但岗位已挂很久 | -2 |
| 发布>30天无任何更新 | -1 |
| 链接失效或联系方式不通 | -2 |
| 公司近期有裁员/冻结但同时在大量招聘 | -2 |
| 公司社保人数持续下降却大量招人 | -2 |

## 六、轴5：欺诈信号（一票否决）

任何一项触发 → 直接 SKIP，不做后续分析。

| 信号 |
|------|
| 要求交费（培训费/押金/设备费/申请费） |
| 面试前索要身份证/银行卡号 |
| 招聘邮件来自个人邮箱（Gmail/Yahoo/QQ）而非企业域名 |
| 薪酬对低技能工作高得不合理 |
| "招转培"模式：高薪诱饵→说你缺技能→推付费培训 |
| "招转贷"模式：诱导签车贷/消费贷 |
| "保录取"/"内部渠道"收服务费 |
| 引导到非主流聊天工具（WhatsApp/Telegram）面试 |
| 公司在工商系统不存在或状态异常 |

## 七、汇总规则

```
if 轴5任何一项触发:
    → SKIP（不可覆盖，不计算其他轴）

轴1-4总分 = 轴1分×0.31 + 轴2分×0.19 + 轴3分×0.25 + 轴4分×0.25

if 总分 ≥ 1.0:
    → PASS — 质量好，继续分析
elif 总分 ≥ -0.5:
    → WARN — 有风险信号，标注后继续
else:
    → SKIP — 质量太差，建议不浪费时间
```

### WARN 输出示例

```
⚠ JD质量：存在风险信号（总分: -1）

  风险标注：
  - "薪资面议" → 大概率低于市场水平
  - "弹性工作制" → 可能无加班费
  - 岗位已发布>30天 → 可能已招到人或低优先级

  → JD本身信息量足够，可以继续分析，但面试时需验证以上风险。
```

### SKIP 输出示例

```
✗ JD质量：建议跳过（总分: -5）

  主要问题：
  - 薪资面议 + 范围10K-30K（跨度3倍）
  - "狼性文化"+"抗压能力强"+"弹性工作制"同时出现
  - 岗位每3周重发一次，已持续8个月
  - 公司社保人数持续下降

  → 建议不浪费时间深度分析。如果非要投，标注为高风险。
```

## 八、平台格式适配

### 各平台共通字段

岗位名称 | 薪资范围 | 工作地点 | 学历要求 | 经验年限 | 技能标签 | 公司名称 | 公司规模 | 行业分类 | 福利标签 | JD正文

### 平台特有

| 平台 | 特有字段 | 对评估的价值 |
|------|---------|------------|
| BOSS直聘 | boss_name、对话状态 | 可判断HR还是业务负责人直招 |
| 猎聘 | 猎头中介信息、高管JD语言 | 薪资范围通常更可信 |
| 拉勾 | 技术栈结构化标签、面试评价 | 技术栈真实性更高，可看前人面经 |
| 51job | 传统模板、制造业为主 | JD模板化程度高，需更仔细看细节 |
| 智联 | 校招专项、VR办公室 | 校招岗位格式不同 |

当平台未知时按"通用"处理，直接从纯文本提取。
