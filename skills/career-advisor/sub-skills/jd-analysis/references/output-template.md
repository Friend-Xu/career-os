# 输出模板

各阶段输出格式。按用户停在哪一阶段决定输出什么。

---

## 阶段1输出：JD 质量快判

```markdown
# JD 质量快判：[岗位名称] @ [公司名]

**评估结果**：[PASS / WARN / SKIP]
**总分**：[X] / 轴5: [触发/未触发]

[如果是PASS]
→ JD质量好，值得深度分析。继续？

[如果是WARN]
⚠ 风险信号：
  - [风险1 — 来源: 轴X]
  - [风险2 — 来源: 轴X]
→ 可以继续分析，但面试时需验证以上风险。继续？

[如果是SKIP]
✗ 建议跳过：
  - [致命问题1]
  - [致命问题2]
→ 不建议在这份JD上继续花时间。如果你坚持要分析，回复"继续"。
```

## 必备技能 (Must-have)
| 技能 | 要求等级 | 备注 |
|------|:--:|------|

## 加分技能 (Nice-to-have)
| 技能 | 备注 |

## 完整报告模式

当用户一路走到阶段4时，四个 section 顺序拼接输出。仅在阶段1判断为 WARN/SKIP 时顶部显示警告横幅：

```markdown
⚠ 本JD存在质量风险信号，详见下方"JD质量快判"。
```

## 批量JD对比模式

```markdown
## JD 对比：[岗位A] vs [岗位B] vs [岗位C]

| 维度 | 岗位A | 岗位B | 岗位C |
|------|-------|-------|-------|
| JD质量 | PASS | WARN | PASS |
| 薪资范围 | 15-25K | 面议 | 20-30K |
| 硬门槛 | 全过 | 学历不满足 | 全过 |
| 硬技能匹配 | 78% | 55% | 82% |
| 关键差距数 | 2 | 4 | 1 |
| 文化红旗 | 1个 | 3个 | 0个 |
| 投递建议 | 定制后投 | 跳过 | 直接投 |

### 推荐排序
1. **岗位C** — 匹配最高 + 质量好 + 无红旗
2. **岗位A** — 匹配好但需面试验证文化红旗
3. **岗位B** — 硬门槛不满足 + 3个文化红旗
```
