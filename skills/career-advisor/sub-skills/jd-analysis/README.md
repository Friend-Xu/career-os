# JD Analysis

JD 智能分析 skill —— 不只是关键词匹配。

拿一份岗位描述，告诉你：
- **靠不靠谱**（JD质量评估 + 欺诈检测）
- **匹不匹配**（证据锚定的匹配度计算 + 差距分类）
- **怎么投**（投递决策 + 简历定制指令）
- **面试会问什么**（问题预测 + 反问生成 + 风险应对）

## 快速开始

```
"帮我分析这个JD：[粘贴JD文本]"
"这个岗位适合我吗？[JD + 简单介绍自己]"
"帮我对比这三个JD：[JD1] [JD2] [JD3]"
```

## 流程

```
阶段1: JD质量评估 → PASS/WARN/SKIP
阶段2: JD深度拆解 → 显性需求 + 隐性信号 + 红旗
阶段3: 匹配度计算 → 证据锚定 + 多维评分 + 差距分类
阶段4: 投递行动包 → 决策 + 简历定制 + 面试准备
```

每个阶段结束可选择停止，不需要一路走到简历定制。
