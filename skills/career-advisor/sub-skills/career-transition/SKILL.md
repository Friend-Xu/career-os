# 职业转行分析
>
> 本文件是 career-advisor skill 的子模块。由主 SKILL.md 路由加载，不作为独立 skill 运行。

**输入你现在的岗位和背景，输出能不能转、怎么转、第一步做什么。**

不做心理按摩，不给虚假希望——从技能审计 + 动机诊断 + 差距分析 + 路径设计四个角度，
帮职场人做出有数据支撑的转行决策。

## 与 career-path / city-advisor / company-screener / company-research 的关系

```
career-path (职业方向层)       →  "我该做什么方向？"
        │ 写 directions/
        ▼
career-transition (转行分析层) →  "怎么从现在的位置走到想去的位置？"
        │ 读 directions/  写 profiles/ + decisions/
        ▼
city-advisor (城市选择层)      →  "我该去哪个城市？"
        │ 写 cities/ + decisions/
        ▼
company-screener (发现层)       →  "这个城市有什么好公司？"
        │ 写 decisions/
        ▼
company-research (评估层)       →  "这家公司值不值得去？"
        │ 写 companies/ + decisions/
        ▼
jd-analysis (岗位层)           →  "这个岗位适合我吗？"
        │ 读 profiles/ + companies/  写 decisions/
        ▼
你决策                        →  "出结论" → 汇总层从 decisions/ 综合
```

**数据全部存在 `workspace/career-advisor/`（运行时）和 `references/`（静态参考）。Skill 之间不直接传递数据——通过信息池交换。**
```

**career-path vs career-transition 的边界**：

| | career-path | career-transition |
|---|---|---|
| 用户 | 应届生/0-3年 | 有工作经验的职场人 |
| 起点 | 白纸，从专业出发 | 有存量：技能、人脉、行业认知 |
| 核心问题 | "我该做什么方向？" | "怎么从现在的位置走到想去的位置？" |
| 约束 | 学校、专业、兴趣 | 薪资不降太多、地理绑定、家庭负担、时间窗口 |

**何时引导用户从 career-transition 切到 career-path**：

```
gap + 什么都没做 + 经验 <2年 + 没有明确目标方向
→ "你可能更适合先走 career-path（方向探索），而不是 career-transition（转行分析）。
   转行分析的前提是你知道'现在在哪'和'想去哪'。
   你现在两个都不太确定——我们切到 career-path 帮你先探索方向。"
```

## 工作流总览

```
入口分流
├─ A. 快速通道 → Step 1轻量 → Step 3轻量确认 → Step 4方向确认 → Step 5差距分析(+简化路径) → Step 7行动计划
└─ B. 完整通道 → 7步全流程

完整通道：
Step 1: 简历/技能导入 → 技能清单 + Gap 审计
Step 2: 岗位审计       → "实际在做什么" vs "简历写了什么"
Step 3: 转行动机诊断   → "先别转"检查
Step 4: 方向探索       → 候选方向画像卡
Step 5: 差距分析       → 加权矩阵 + 四象限 + 财务模型 + 风险调节
Step 6: 路径设计       → 跳板模式匹配 + 时间线
Step 7: 行动计划       → 周/月/季度 + 故事线包装
```

## 入口分流

```
"你现在是什么情况？

A. 我清楚想转到哪个方向 → 快速通道
   （比如"我从机械设计想转机器人"，只需要差距分析和怎么转）

B. 我想离开现在的工作，但不知道去哪 → 完整通道
   （需要从技能+兴趣+市场三个角度探索可能的转行方向）"
```

### 入口升级规则

快速通道用户在以下情况下自动升级到完整通道：

| 触发条件 | 升级原因 |
|---------|------|
| 有 gap + gap 期间什么都没做 | Sprint 用户需要完整技能审计和动机诊断 |
| 快速通道轻量确认发现"红旗"（gap方向不一致、Push驱动为主、对目标方向了解仅限"听说"） | 轻量确认不足以处理复杂动机情况 |
| 用户中途说"不确定了" | 方向探索需要完整通道的 Step 4b/4c |

### Sprint 完成后重新进入

当用户完成 Gap 重启 Sprint 后回到对话时：

1. 询问 Sprint 第 4 周的决定："4 周 Sprint 完成了，你的决定是什么？"
2. 根据决定路由：
   - "我想继续深入 X 方向" → 检查当前入口 → 若是快速通道，自动升级到完整通道
   - "我还是不确定" → 引导到 career-path 做全景探索
   - "我其实没那么想离开现在的行业" → 运行 Step 3 动机诊断 → 转交 city-advisor + company-screener

## Step 1: 简历/技能导入

Read `references/skill-audit-guide.md` 获取完整技能清单和提取规则。

### 执行方式

**1a. 简历导入（可选）**：

> **快速通道精简范围**：快速通道用户跳过 Gap 显式询问（1c）和 7 大类全量展开。
> 只做核心技能确认：从简历提取 or 用户口述当前岗位的 3-5 项核心技能 +
> 目标方向已知或疑似的前置技能。Gap 方向一致性判断合并到 Step 3 轻量确认中。

```
"你有现成的简历吗？（PDF/Word/文本都行，粘贴内容或告诉我文件路径）

有简历的话我可以自动提取你的技能清单，你只需要补充修正。
没有也没关系，我们手动过一遍技能清单，5-10 分钟。"
```

- 有简历 → Read 提取：工作年限、公司序列、职位序列、项目关键词、技能关键词
- 自动预勾选技能清单 → 用户确认/修正/补充

**1b. 结构化技能清单**（完整通道）：

7 大类（详见 skill-audit-guide.md）：
1. 技术硬技能
2. 行业领域知识
3. 工具与软件
4. 项目与流程管理
5. 沟通与人际
6. 商业与战略
7. 自我管理

每项标注熟练度：精通 / 熟练 / 接触过 / 不想再用

**1c. Gap 显式询问**：

```
"你的工作经历中有没有超过 3 个月的空档期？
比如考研、考公、身体原因、家庭原因等。
（有gap很正常，如实说就行，这会影响转行策略的设计）"

→ Gap 长度: [  ] 个月
→ Gap 原因: [考研/考公/健康/家庭/找工作/其他:____]
→ Gap 期间做了什么: [____]
  （如果考研，考的什么专业？如果自学了什么，具体是什么？）
```

**Gap 处理路由**：

```
├─ Gap 期间做了具体事情 → Gap 成长审计 → 技能映射（知识→"接触过"级别）
│   └─ 如果考研方向 = 转行目标方向 → 加速器，gap期间积累可认证
│   └─ 如果考研方向 ≠ 转行目标方向 → 标注"注意：你上次gap选择了不同方向"
└─ Gap 期间什么都没做 → Gap 重启 Sprint（skill-audit-guide.md 章节）
    └─ 在当前对话中输出 4 周重启计划，告知"完成 Sprint 后随时回来继续"
```

**输出**：初始技能画像 + Gap 备注 +（如适用）Gap 重启 Sprint

**1d. 隐藏技能追问（快速通道 · 30秒）**：

快速通道跳过 Step 2（岗位审计），但隐藏技能影响差距分析的"差异化优势"维度（15%权重）。用一个问题引出：

```
"最后一个问题：有没有什么事，你做起来觉得很简单，
 但发现别人做起来挺费劲的？

 比如：把复杂技术问题讲清楚让外行听懂、把混乱流程理顺、
 说服不配合的部门配合你、在信息不全时快速做判断……

 → 这些东西往往不会写在简历上，但在转行时是你的差异化武器。"

输出: 在技能摘要末尾标注"隐藏技能: [X, Y]"
用途: Step 5 差异化优势维度（15%权重）中作为加分证据
```

## Step 2: 岗位审计

### 目的

挖掘"实际在做什么"——简历不会写的隐藏技能。有经验的人往往低估自己的可迁移能力。

### 执行方式

基于 Step 1 的技能清单，追问三个问题：

```
"基于你的技能清单，我想再确认三个问题：

1. 你现在日常工作中，时间花最多的是哪三件事？
   （不是简历上的，是实际每天/每周在做的）

2. 有没有你做得很好但不在技能清单里的事？
   比如：帮同事解释技术问题（培训能力）、把混乱的流程理顺（流程优化）、
   说服其他部门配合你的工作（跨部门推动）...

3. 现在的岗位，你觉得最没价值/最不想带到下一份工作的是什么？"
```

### 产出

```
经过审计的技能画像：

  核心竞争力（精通+做得好+市场需要）:
    [技能A] — 在 [场景] 中体现
    [技能B] — 在 [场景] 中体现

  隐藏技能（做得好但简历没写）:
    [技能X] — 比如"帮三个新同事快速上手"→ 培训/mentoring能力

  不想再用的技能:
    [技能Y] — 下一份工作尽量避免用到

  有效工作年限: X 年（扣除gap后）
```

## Step 3: 转行动机诊断（"先别转"检查）

Read `references/motivation-check.md` 获取完整诊断逻辑。

### 核心原则

**"先别转"检查不阻断流程——但警告会一直在。**

### 快速通道（入口 A）的轻量确认

快速通道跳过完整动机诊断，但必须做一句话确认，不能直接跳过：

```
"两个问题帮我确认你的动机：

1. 你想离开现在的工作，主要是因为什么？
   （一句话概括——'工作重复没有成长'、'行业走下坡路'、
    '就是对 [目标方向] 感兴趣'、'老板/团队有问题'）
   → 追问: 这个问题，换一家公司（同一方向）能解决吗？

2. 你对 [目标方向] 的实际了解来自于什么？
   → 做过项目/深度研究/跟从业者深聊过 → Pull 验证充分，动机扎实
   → 网上看过文章/听朋友说薪资高 → Pull 需要验证，
     建议 Step 4 看完画像卡后再确认一次
   → gap期间系统学过相关方向 → 标注'gap已验证方向一致性'

→ 综合判断:
  问题1 "换公司可解" + 问题2 "听说不错" → 红旗:"建议切换到完整通道"(可忽略)
  问题1 "换公司可解" + 问题2 "验证充分" → 矛盾信号,归为"需要验证"
  问题1 "方向问题" + 问题2 "验证充分" → 动机扎实
  问题1 "方向问题" + 问题2 "听说不错" → 标注"需要验证Push+验证Pull,建议低成本测试"
```

> Gap 方向一致性判断与 Step 1 的 Gap 处理路由共用同一逻辑（skill-audit-guide.md 第四部分）。
> 两者不会给出矛盾结论——Step 1 输出 Gap 备注，Step 3 轻量确认直接引用。

**红旗自动升级规则**：轻量确认中出现以下任一情况时，标注"建议切换到完整通道"并说明原因：

| 红旗信号 | 说明 |
|---------|------|
| gap 方向 ≠ 目标方向 | 可能存在"用转行逃避"的模式重复 |
| 对目标方向的了解仅限"听说薪资高" | Pull 驱动薄弱，需要完整动机诊断 |
| 离职原因中提到 3+ 个 Push 因素 | 可能是公司问题而非方向问题 |

> 用户可选择忽略升级建议继续快速通道，但红旗标注会带到后续输出中。

此轻量确认的输出标注在 Step 4 方向确认卡片之前。

### 执行方式（完整通道）

```
"在探索转行方向之前，我们先做个快速诊断——你到底是想'离开现在的工作'，
还是想'去某个方向'？这两个不一样。"

逐项问：

1. 你想离开现在的工作，主要是因为什么？（可以多选）
   □ 老板/团队有问题      □ 薪资不满意
   □ 加班太狠             □ 工作内容重复无聊
   □ 行业没前途           □ 公司经营不善
   □ 学不到东西           □ 价值观不合
   □ 就是想换个赛道

2. [对每个选中的因素追问]:
   "这个问题，在同一个方向换一家公司能解决吗？"
```

### 诊断输出

详见 motivation-check.md 的 Push/Pull 分析矩阵。三种诊断结果：

| 诊断结果 | 输出 |
|---------|------|
| **先别转** | 问题主要是公司/团队层面。建议先在当前方向换一家公司。⚠警告标注在后续所有输出顶部。 |
| **需要验证** | 转行方向合理但了解不够深。建议先做 1-2 个月低成本测试。继续走完整流程。 |
| **转行合理** | Push 因素确实且不可解 + Pull 方向经过验证。继续走完整流程。 |

**Gap 驱动的焦虑检测**（如有 Gap）：

```
"你有一段考研gap。这个信息在转行决策中很重要：

→ 考研行为本身暗示你对原方向可能有未说出口的不满意
→ 如果考研方向跟你想转的方向一致 → 这不是零基础转行
→ 如果考研方向跟转行方向完全无关 → 注意：
  你可能在重复'用考试/转行逃避当下'的模式。花点时间确认这次是真的想清楚了。"
```

> ⚠ 如果诊断结果是"先别转"但用户坚持继续 → 在 Step 5-7 的所有输出顶部标注：
> "提醒：转行动机诊断显示你的问题可能主要在公司/团队层面，换一家公司或许就能解决。
> 以下是你要的转行分析，但建议同时考虑在当前方向找更好的机会。"

## Step 4: 方向探索

### 快速通道（入口 A）

用户已经知道目标方向 → 直接展示该方向的画像卡 + 市场数据确认：

```
"你说想从 [当前岗位] 转到 [目标方向]。在分析差距之前，先确认一下：

[目标方向] 的日常：[画像卡·来自 career-path-map.md]

市场数据 [WebSearch·实时]：
- 社招薪资范围: [X-Y万]
- 主要城市: [列表]
- 当前招聘趋势: [增长/平稳/收缩]

→ 看完这些，你依然确定这是你想去的方向吗？"
```

如果用户说"不确定了" → 切到完整通道 Step 4。

### 完整通道（入口 B）

三个维度发散探索：

**4a. 技能指向**：
```
"从你的技能画像出发，以下方向跟你的可迁移技能重叠度高：
  [方向A] — 重叠技能: [X, Y, Z]
  [方向B] — 重叠技能: [X, W]
  [方向C] — 重叠技能: [Y, Z]
→ 这些方向你了解过吗？有没有感兴趣的？"
```

**4b. 兴趣指向**（复用 IKIGAI 四问，但更聚焦）：
```
"抛开'能不能转'的问题，你对什么方向有兴趣？
（不用想现实不现实，就说你感兴趣的）
→ 在 career-path 的画像卡中，哪些方向让你觉得'这可能是我想做的'？"
```

**4c. 市场信号**：
```
WebSearch: "[用户当前行业/岗位] 转行 方向 2025 2026"
→ 找真实转行案例 + 市场需求的验证
```

**产出**：3-5 个候选方向（复用 career-path-map.md 画像卡）

## Step 5: 差距分析

Read `references/gap-analysis-model.md` 获取完整算法和建模公式。

### 五个子模块

**5a. 加权差距矩阵**：

对每个候选方向：
- 技能需求拆解：Critical（关键）/ Important（重要）/ Supporting（辅助）
- 用户技能评级：精通 / 熟练 / 接触过 / 零基础
- 计算：技能重叠度 % + 加权差距分

详见 gap-analysis-model.md。

**5b. 差距 × 重要性优先级矩阵**：

```
              │ Small Gap        │ Large Gap
──────────────┼──────────────────┼──────────────────
High Importance│ Quick Win        │ Critical Path     ← 优先投入
              │ (2-4周搞定)       │ (3-6个月重点攻)
──────────────┼──────────────────┼──────────────────
Low Importance │ Defer            │ Ignore
              │ (入职后再补)      │ (不值得投入)
```

**5c. Cedefop 四象限**：

- X 轴：技能重叠度（定量，5a 算出）
- Y 轴：市场可观测性（定性，WebSearch 推断 · 质量分级）
  - 搜索 `"[当前岗位] 转 [目标方向] 经验 路径"`
  - 强可观测/中可观测/弱可观测（详见 gap-analysis-model.md 两步判定法）

```
              强可观测 ↑
    Q1: 软着陆          |    Q2: 顺滑过渡
   低重叠+有人走通过     |   高重叠+市场验证充分
   策略：中间跳板/内部转岗 |   策略：直接投简历
   ─────────────────────────────────────→ 技能重叠度
    Q3: 不建议           |    Q4: 隐形机会
   低重叠+无案例         |   高重叠+少有人走
   策略：回学校/长期自学  |   策略：强故事线+直接投
              弱可观测 ↓
```

**5d. 风险调节系数**：

```
风险调节 = 经验年限(35%) + 财务缓冲(40%) + 家庭约束(25%)
```

详见 gap-analysis-model.md。

**5e. 财务模型**：

```
转行后收入预测 vs 不转行基线：

          Y1      Y3      Y5      5年累计    回本时间
不转行    X万     X'万    X''万    XXX万     —
转行      Y万     Y'万    Y''万    YYY万     Z年
差额      -Δ1     +Δ3     +Δ5     累计差     —
```

**产出**：每个候选方向的差距报告（5a-e 全部包含）

### 快速通道：简化路径判断

快速通道跳过 Step 6（路径设计），在 Step 5 末尾嵌入简化版路径选择：

```
技能重叠度 ≥ 70% → 直接路径：[当前岗位] → [目标岗位]（1-3 个月）
  行动: 包装简历 + 投递 + 面试准备

技能重叠度 50-70% → 准备路径：需要 3-6 个月针对性补强
  行动: 补齐 Critical Path 技能后投递

技能重叠度 30-50% → 跳板路径：需要中间岗位过渡（6 个月 - 2 年）
  行动: 先找中间岗位，在中间岗位积累目标方向的经验

技能重叠度 < 30% → 长期路径：需要 1 年+ 系统学习
  行动: 在职学习为主，不裸辞；或考虑是否需要回学校
```

此简化判断替代完整通道 Step 6 的跳板模式匹配和详细时间线。

## 边界情况

### 转行方向跨度极大（如文科转AI）
诚实告知难度（"技能重叠度低，需要回学校或从头自学 1-2 年"），不强推。
建议先在业余时间测试（"周末做一个 X 项目，看自己是否真的喜欢"）。
标注"该方向不在 career-path-map.md 的预设映射中，分析基于搜索推理"。

### 财务缓冲 <3 个月 + 有家庭负担
风险调节系数 ≥1.3 → 所有路径推荐自动转为"在职学习"或"内部转岗"。
不推荐裸辞或脱产学习。

### 用户说"什么都想转，就是不想干现在这个"
先运行 Step 3 动机诊断。大概率诊断结果是"先别转"——
问题可能是职业倦怠而非方向错误。建议：
1. 先用 career-path 做方向探索
2. 同时建议在当前公司内部尝试转岗（低成本测试）

### Gap 重启 Sprint 中用户说"我还是不知道"
回到 Step 1 结尾的判断逻辑 → 可能更适合 career-path 而非 career-transition。

### 完全搜不到转行案例（市场可观测性 = 0）
四象限落入 Q3。诚实告知："从公开数据看，这个转行路径少有先例。
这不意味着不可能，但意味着你需要自己开辟这条路——
没有成熟的中间跳板、没有可以抄的作业。"

## 质量规则

1. 每条信号标注来源类型和年份
2. 薪资数据标注年份和来源平台
3. 推断类判断标注 `[推断]`，与事实类信息区分
4. 查不到就说查不到，不编造数据
5. **不给虚假希望**——难就是难，给具体的"怎么开始"而不是空洞的"可以实现"
6. **"先别转"警告不可绕过**——诊断结果是"先别转"时，警告在后续所有输出中持续显示
7. **财务约束是最硬的约束**——风险调节系数 ≥1.3 时，不推荐裸辞或脱产学习
8. **Gap 不评判**——"gap 期间什么都没做"不是失败，是常见的恢复期。从今天开始比往回看重要
