## 二、熟练度分级

每项技能标注熟练度：

| 级别 | 标记 | 含义 |
|:--:|:--:|------|
| 精通 | ★★★ | 能独立解决复杂问题，能带人，在同龄人中前 20% |
| 熟练 | ★★ | 能独立完成常规工作，偶尔需要指导 |
| 接触过 | ★ | 学过或用过，但不能独立完成，需要监督 |
| 系统自学 | ★+ | 系统学过理论（如课程/考研备考/培训），但没有实战经验。介于"接触过"和"熟练"之间——理论扎实但缺实践。常见于 gap 期间的自学、跨专业考研备考等场景 |
| 不想再用 | ✗ | 有这个技能但下一份工作希望避免用到 |

"系统自学"(★+) 主要用于 gap 期间的知识映射。在差距计算中，其数值等级 = 2.5（介于接触过=2 和熟练=3 之间）。与"接触过"的区别：接触过=随便学过一点；系统自学=完整学过但没机会用。

"不想再用"是重要的方向信号——它告诉你下一份工作不该做什么。

## 三、简历提取规则

### 可提取的字段

从简历中自动提取，按可靠性排序：

| 字段 | 提取方式 | 可靠性 |
|------|---------|:--:|
| 工作年限 | 从最早工作经历推算 | 高 |
| 公司序列 | 工作经历中的公司名 | 高 |
| 职位序列 | 工作经历中的职位名 | 高 |
| 学历/专业 | 教育背景 | 高 |
| 技能关键词 | 技能标签 + 项目描述中的动词 | 中 |
| 项目关键词 | 项目名称 + 描述中的技术名词 | 中 |
| 行业领域 | 从公司 + 职位推断 | 低 |

### 关键词 → 技能映射

| 简历中的词 | 映射到技能清单 |
|-----------|-------------|
| SolidWorks/CATIA/NX/ProE/Creo | → 技术硬技能: 机械设计 |
| ANSYS/Abaqus/HyperWorks | → 技术硬技能: 仿真分析 |
| Python/C++/Java/嵌入式 | → 技术硬技能: 编程开发 |
| PLC/电路设计/PCB | → 技术硬技能: 电气/电子 |
| APQP/FMEA/PPAP/SPC | → 行业领域: 汽车 |
| ISO 13485/FDA/CE | → 行业领域: 医疗器械 |
| 供应商开发/询价比价/ERP | → 项目流程: 供应商管理 |
| 专利/论文/技术方案 | → 沟通人际: 技术写作 |

### 简历预填流程

```
1. Read 简历文件 → 提取文本
2. 关键词匹配 → 自动勾选技能清单中的对应项
3. 展示给用户 → "以下是根据你的简历自动填的技能清单，你看对不对？
   有没有漏的？有没有标错了的？"
4. 用户确认/修正/补充
5. 追问熟练度分级（对每个勾选项快速过一遍）
```

### 如果简历太老或过时

```
"你的简历看起来是 [年份] 更新的——有没有你做过但没写在简历上的事？
比如最近的项目、自学的技能、或者工作之外积累的能力？"
```

## 四、Gap 处理

### Gap 的五种模式

以下分类与 action-plan-template.md 的 Gap 话术表保持一致：

| 类型 | 常见原因 | 对转行的影响 |
|------|---------|------------|
| 考研/考公 gap | 对原方向摇摆 + 想找更好出路 | 暗示 push 因素，gap 期间的知识可能可认证 |
| 健康/家庭 gap | 被动中断 | 可能有工作强度/地点的特殊需求 |
| 找不到工作 | 市场信号问题 | 方向可能选错了，优先考虑市场需求强的方向 |
| 主动探索 | 旅行/副业/重新定位 | 信息量最大，通常有明确的"想清楚了" |
| 什么都没做 | 消沉/恢复期 | 启用 Gap 重启 Sprint，不评判 |

### Gap 成长审计（gap 期间有具体行动时）

```
"你gap期间做的 [X]，我们把它映射到技能体系：

  [做的具体事情] → 可认证为 [技能]（接触过级别）
  [做的具体事情] → 可认证为 [技能]（接触过级别）

→ 如果考研方向 = 目标转行方向：
  '这一年不是空白——你系统学习了 [专业知识]，
   这意味着你不是零基础转行，是'有一定理论基础+缺实践经验'。'

→ 如果考研方向 ≠ 目标转行方向：
  '注意：你上一次gap选择了 [考研方向]，这次想转的是 [转行方向]。
   两个方向不一样。花点时间确认——这次是真的想清楚了，
   还是在重复'用考试/转行逃避当下'的模式？'"
```

### "加速器"的含义

当用户 gap 方向（考研/考公/自学）与目标转行方向一致时，gap 期间积累体现为三个层面的加速：

1. **技能评级提升**：gap 期间系统学习过的知识映射为"系统自学"(★+, 数值 2.5)，而非"接触过"(★, 数值 2.0)。在差距计算中：`等级差 = 目标要求 - 2.5`（而非 `目标要求 - 2`）。
2. **学习时间缩短**：因为理论基础已有，Critical Path 技能的预计学习时间缩短 30-50%。如运动学从"3-4 个月"变为"2-3 个月"。
3. **面试叙事加分**：gap 经历可包装为"我花了一年验证自己对这个方向的热情"，而非被追问"那一年你做了什么"。

> 注意：加速器只影响技能评级和时间估算，不改变四象限定位和风险调节系数。

### Gap 重启 Sprint（gap 期间什么都没做时）

当用户说"gap 期间什么都没做，就是消沉了半年"时启用。

**前置声明**（必须放在最前面）：

> gap 期间消沉是正常的。考研失败后每个人都需要恢复期。
> 我们不看过去，从今天开始。

```
## Gap 重启 Sprint：4 周重建节奏

每周只做一件事。完成就打勾。

### 第 1 周：建立节奏

□ 每天固定时间起床（不要求很早，但要求固定，比如每天 9:00）
□ 每天出门一次（哪怕是下楼买瓶水）
□ 周末前完成：列出 3 个你"可能感兴趣"的职业方向
  （不需要确定，只需要好奇）

→ 本周唯一目标：恢复基本的日常节奏。不需要学任何东西。

### 第 2 周：信息摄入

□ 针对上周列的 3 个方向，每个方向：
  - 在 BOSS 直聘/智联上搜一下，看 10 个岗位 JD（不需要投，只看）
  - 在小红书/知乎搜"[方向名] 日常做什么"，读 3 篇真实分享
□ 周末前完成：对 3 个方向排个序——哪个让你最好奇？

→ 本周目标：从"完全不接触"变成"至少知道这些方向大概做什么"

### 第 3 周：轻量尝试

□ 选排第一的方向，找一个最低成本的尝试方式：
  - 如果是技术方向 → B站搜入门教程，跟着做完第一个 demo
  - 如果是非技术方向 → 找 1 个从业者聊（脉脉/校友群/LinkedIn）
□ 周末前完成：写下"我试了 X 之后，感觉 Y"

→ 本周目标：从"知道"到"试过"。试过之后的感觉才是真实信息。

### 第 4 周：做出一个决定

□ 基于前三周的体验，做出一个决定：
  - "我想继续深入 X 方向" → 回到 career-transition Step 2 岗位审计
  - "我还是不确定" → 建议切到 career-path 做全景探索
  - "我其实没那么想离开现在的行业" → 告知 AI "我不想离开现在的行业，想在同方向找更好的机会"。AI 会重新运行 career-transition Step 3 动机诊断，确认后引导你使用 city-advisor + company-screener 在同方向找公司和城市。

→ 本周目标：做出一个决定。不管什么决定，都比悬在空中好。
```

### Sprint 与后续流程的衔接

```
在当前对话中：
  输出完整的 4 周 Sprint 计划
  + "完成 Sprint 后随时回来继续。前两周只是信息吸收，第三周开始
     你会有真实的感受——那时候再来做差距分析会更有效。"

判断是否应该切到 career-path：
  gap + 什么都没做 + 经验 <2年 + 没有明确目标方向
  → "你可能更适合 career-path（方向探索），而不是 career-transition。
     你现在两个都不太确定——这很正常。先探索方向，确定后再回来做转行分析。"
```
