# 转行动机诊断（"先别转"检查）

区分"逃避现在"（Push）和"向往新方向"（Pull）。
"先别转"不阻断流程，但警告会在后续所有输出中持续显示。

---

## 核心判断树

```
                    ┌─ 是 ──→ "先别转"信号强
                    │
  离职动机主要是Push? ──┤
  （逃避现在的工作）   │
                    └─ 否 ──→ 主要是Pull（向往新方向）
                                   │
                                   └─ 你为新方向做过什么？
                                      ├─ 做过项目/深度了解 → 转行动机扎实
                                      └─ 只是"觉得不错" → 建议先测试再决定
```

---

## Push 因素分析矩阵

| Push 因素 | 换个公司能解决？ | 换个岗位能解决？ | 换行业才能解决？ |
|-----------|:---:|:---:|:---:|
| 老板差/团队 toxic | ✓ | - | - |
| 薪资不满意 | ✓ | - | - |
| 加班太狠 | ✓ | ✓ | - |
| 工作内容重复无聊 | - | ✓ | ✓ |
| 行业没前途 | - | - | ✓ |
| 公司经营不善 | ✓ | - | - |
| 学不到东西 | ✓ | ✓ | ✓ |
| 价值观冲突 | - | - | ✓ |

### 逐项追问模板

对用户勾选的每项，追问：

```
"你说 [push因素]。这个问题，在同一个方向换一家公司能解决吗？

  比如：
  - 如果是'加班太狠' → 非标自动化普遍加班，但医疗器械的结构设计岗节奏正常很多
  - 如果是'学不到东西' → 换一家项目更多的公司，或者从量产厂跳到研发型公司
  - 如果是'行业没前途' → 那确实需要换行业，不是换公司"
```

### Push 因素总和判断

| Push 因素中"换公司可解"的占比 | 判断 |
|:--:|------|
| ≥ 60% | 问题主要在公司，不是方向。强烈建议先尝试在当前方向换公司 |
| 30-60% | 混合型。部分可解，部分需要转行 |
| < 30% | 方向问题为主，转行动机合理 |

---

## Gap 驱动的焦虑检测

当用户存在 gap 时触发额外检查：

```
"你有一段 [考研/考公] gap。我们需要区分两种可能：

  可能性 1：gap 是你在理性评估后选择的方向调整
    → 如果考研方向 = 转行目标方向，这不是零基础

  可能性 2：gap 反映了你习惯用'下一次考试/下一次转行'来逃避当下的困境
    → 考研→失败→转行 是不是同一个模式的重复？
    → 如果这次转行也不顺利，你的 Plan B 是什么？

  这个没有对错，但值得你自己想清楚。"
```

### 焦虑驱动的转行信号

出现以下模式时标注"注意：可能是焦虑驱动而非理性选择"：

- gap 后急于求成（"必须三个月内转成"）
- 目标方向跟 gap 期间的方向完全不同（"考研考的是金融，现在想转AI"）
- 对目标方向的了解仅限于"听说薪资高"
- 说不出"不转行"的 Plan B

---

## 三种诊断结果（含优先级规则）

当诊断条件出现冲突时，按以下优先级裁决：

```
优先级 1 (最高): Push 因素"换公司可解"占比 ≥ 60%
  → 无论 Pull 是否有验证，统一归为"先别转"
  → 因为：大部分问题换公司就能解决，转行的必要性存疑
  → 例外：如果 Pull 有验证且 Push 中"行业没前途"也被勾选 → 归为"矛盾信号"

优先级 2: Push 因素"换公司可解"占比 < 30% + Pull 完全无验证
  → 归为"需要验证"
  → 因为：虽然现有方向确实有问题，但目标方向也未经检验
  → 建议：先做 1-2 个月低成本测试再决定

优先级 3 (默认): 其他所有组合
  → 按原触发条件正常分类
```

### 1. 先别转

**触发条件**：Push 因素中"换公司可解"占比 ≥ 60%（不论 Pull 验证状态）。

但如果 Pull 有验证 且 Push 中"行业没前途"也被勾选 → 归为"矛盾信号"（见下方）。

**输出模板**：

```
## 转行动机诊断：建议先别转

你的离职动机主要是 [因素列表]。

其中 [X个因素] 在同一个方向换一家公司可能就能解决：
  • [因素1] — 换到 [类型的公司] 可能会有改善
  • [因素2] — 这不是方向问题，是公司问题

你对目标方向 [方向名] 的实际了解还比较浅（[证据]）。

→ 综合判断：建议先别转。在当前方向换一家更好的公司试试。
  用 city-advisor 找适合的城市 + company-screener 发现好公司。

→ 如果你坚持要转：以下是你要的转行分析。
  但建议至少同时投几份当前方向的简历，给自己多一个选项。
```

**后续输出中的警告**：

```
⚠ 提醒：转行动机诊断显示你的问题可能主要在公司/团队层面，
换一家公司或许就能解决。以下分析假设你坚持转行。
```

### 2. 需要验证

**触发条件**：Push + Pull 混合，方向选择合理但了解不够深

**输出模板**：

```
## 转行动机诊断：方向合理，需要验证

你的离职动机中 [X个] 确实需要转行才能解决（[列表]）。

你对 [目标方向] 有兴趣，但目前的了解还停留在 [状态]。
建议在正式转行前花 1-2 个月做低成本测试：
  • 做一个 [具体项目]
  • 找 3 个在 [目标方向] 工作的人深聊
  • 投 5 份简历测试市场反馈

→ 继续走完整流程。但把"先测试再决定"作为后续行动计划的第一步。
```

### 3. 转行合理

**触发条件**：Push 因素确实且不可解 + Pull 方向经过验证

**输出模板**：

```
## 转行动机诊断：转行合理

你的离职动机中 [X个因素] 需要转行才能解决。
你对 [目标方向] 的了解基于 [实际探索/项目/从业者交流]。

→ 继续走完整流程。转行动机扎实。
```

### 4. 矛盾信号

**触发条件**：Push 可解 ≥ 60% + Pull 有验证 + Push 中"行业没前途"被勾选。
（既想逃离现状又经过验证地向往新方向——两个信号都强但方向相反。）

或：Push 可解 ≥ 60% + Pull 有验证 + Push 中包含"行业没前途"。
（既想逃离现状又经过验证地向往新方向——两个信号都强但方向相反。）

> 注：Push 可解 < 30% + Pull 完全无验证 已被优先级 2 路由到"需要验证"，不会到达此处。

**输出模板**：

```
## 转行动机诊断：矛盾信号

你的情况比较复杂：

→ 一方面，[Push因素分析]
→ 另一方面，[Pull因素分析]

这两个信号指向不同的结论。

建议分两步走：
1. 先解决"行业没前途"的问题（用 career-path 探索方向 or 在当前行业换公司）
2. 对目标方向做 1-2 个月低成本测试，验证 Pull 信号是否扎实

→ 继续走流程，但在行动计划中加一条"一个月后重新评估转行必要性"的检查点。
```

---

## 执行注意事项

1. **不评判用户的离职原因**——"老板太差"可能是事实，不要说"你要学会适应"
2. **区分"行业没前途"和个人情绪**——如果一个行业整体在增长但用户说没前途，追问具体原因
3. **"就是想换个赛道"需要追问**——"换赛道"太模糊，追问"换到哪？为什么是那个方向？"
4. **Gap 焦虑检测要温和**——不是在质疑用户的判断，是帮他排除干扰信号
