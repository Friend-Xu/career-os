# 行动计划输出模板

周/月/季度三级行动计划 + 故事线包装 + 风险预案。

---

## 行动计划结构

```
本周（启动）    → 3-5 个具体行动，每个 <2 小时可完成
本月（建立节奏） → 3-5 个行动，建立持续投入的习惯
本季度（里程碑） → 2-3 个关键结果，可写到简历上
故事线包装      → 把背景+gap+转行整理成面试中的连贯叙事
风险预案        → 如果关键假设不成立，Plan B 是什么
```

---

## 一、本周行动（启动）

设计原则：
- 每项行动 <2 小时完成
- 不需要前置知识
- 完成后立刻有"我开始了"的正反馈

```
### 本周（启动）

□ [行动 1] — [预计耗时] + [具体资源]
  例: 在 Coursera 上注册 "Modern Robotics" 专项课程
      耗时: 30 分钟 | 资源: https://www.coursera.org/specializations/modernrobotics

□ [行动 2] — [预计耗时] + [具体资源]
  例: 在 BOSS 直聘上搜"机器人 机械设计"，截图 10 个 JD，标注常见要求
      耗时: 1 小时 | 资源: BOSS直聘/智联招聘

□ [行动 3] — [预计耗时] + [具体资源]
  例: 在小红书/知乎搜"机械转机器人 经验"，读 3 篇真实分享，做笔记
      耗时: 1.5 小时 | 资源: 小红书/知乎搜索

□ [行动 4] — [预计耗时]
  例: 打开 SolidWorks，画一个简单的机器人关节装配体，评估自己现在的水平
      耗时: 2 小时
```

---

## 二、本月行动（建立节奏）

设计原则：
- 每周有固定的投入时间（如"每周二四晚上 8-10 点"）
- 开始产生可展示的产出
- 联系 1-2 个从业者

```
### 本月（建立节奏）

□ 完成 [课程名称] 的前 [X] 周内容
  例: 完成 Modern Robotics 专项课程的第 1-2 周（旋转矩阵、DH参数法）
  投入: 每周 4-6 小时 | 资源: Coursera

□ 开始 [项目名称] 的第一个模块
  例: 用 MATLAB 做 6 轴机械臂的正运动学仿真（先不用管逆解，先让它在屏幕里动起来）
  投入: 每周 4-6 小时 | 资源: MATLAB（学校邮箱可能还能用）或 Python+NumPy 替代

□ 联系 [X] 个在目标方向工作的人
  例: 在脉脉上找 3 个在机器人公司做本体设计的工程师，发私信约 15 分钟电话
  "你好，我是做机械设计的，想转机器人方向，能请你喝杯咖啡聊聊日常吗？"

□ 投 [X] 份简历测试市场反馈
  例: 投 5 份机器人公司的机械设计岗（不需要是理想公司，先测试会不会有面试邀请）
  如果 0 回复 → 说明简历需要重新包装技能映射
```

## 三、本季度行动（关键里程碑）

设计原则：
- 产出可以写到简历上的成果
- 完成一个"有说服力的完整作品"

```
### 本季度（关键里程碑）

□ 完成 [课程/认证]
  产出: 证书 + 可展示的项目代码

□ 完成 [Demo 项目]
  产出: 一个完整的、可以给面试官演示的作品
  例: 一个 3D 打印的 6 轴机械臂 + 运动学仿真 + GitHub 项目文档
  这个项目证明: ① 机械设计能力 ② 运动学理论基础 ③ 动手建造能力

□ 更新简历
  产出: 面向目标方向的简历
  重点: 技能映射——"SolidWorks机械设计" → "机器人本体结构设计"
         "做过传动机构" → "熟悉减速器和传动链设计"
         "用过MATLAB做仿真" → "有运动学仿真经验"

□ 拿到 [X] 个面试邀请 or 确定方向不可行
  如果季度末还没拿到任何面试 → 重新评估：
  - 方向选择是否有问题？
  - 技能重叠度是否被高估了？
  - 是否需要先走中间跳板路径？
```

## 四、故事线包装

帮用户把背景 + gap + 转行整理成面试中能讲通的叙事。
不是造假——是把真实的经历用有说服力的方式组织起来。

### 模板

```
## 你的面试故事线

### 一句话版（电梯演讲）
"[当前岗位]背景 + [gap说明（如有）] + [转行动机] + [为转行做的准备]"

例: "我做了 5 年非标自动化机械设计，中间花了一年系统学习机器人运动学
    和控制基础，确定了自己更喜欢'能动的机械'。之后我做了 XX 项目来验证
    自己的方向，现在找机器人本体设计的机会。"

### 完整版（面试 2 分钟自我介绍）

1. 我的背景是 [专业/学校/当前岗位]
   "我是某大学机械工程毕业，做了 5 年非标自动化结构设计。"

2. 我为什么想转 [目标方向]
   "在设计过程中，我对机构的运动学和动力学越来越感兴趣——
   不只是'这个零件会不会断'，而是'它怎么动'。
   传统结构设计解决的是静态问题，我更想做动态系统的设计。"

3. 我gap期间做了什么 [如有gap]
   "我花了一年时间准备机器人方向的研究生考试。虽然考研没成，
   但这一年让我确认了两件事：第一，我对机器人是认真的，
   不是一时兴起；第二，我学完了运动学和控制理论基础，
   这意味着我不是零基础转行。"

4. 我做了什么来证明自己
   "之后我做了 XX 项目，用 [技术栈] 做了一个 [具体成果]。
   这个项目证明我能独立完成 [核心能力]。"

5. 我为什么投这个岗位
   "贵司的 [产品/业务] 在 [方面] 让我很感兴趣。
   我的机械设计背景 + 机器人项目实践，
   让我能在这个岗位上同时贡献结构设计能力和系统理解。"
```

### Gap 专用话术

| Gap 类型 | 话术方向 |
|---------|---------|
| 考研（方向一致） | "我用这一年系统学习了目标方向的基础，虽没考上但知识留下了" |
| 考研（方向不同） | 仅当动机诊断为"转行合理"时使用正面话术："那一年让我明确了自己不适合学术界，更擅长/更喜欢落地执行的工作"。否则标注"在面试中可以这样说，但内部分析建议注意模式重复风险" |
| 考公 | "备考过程让我确认了自己不适合体制内，回归行业发展是更对的选择" |
| 健康 | "需要一段时间恢复，现在已经完全好了"（不需要展开，HR不能追问健康隐私） |
| 家庭 | "家里有些事情需要处理，现在处理完了，可以全身心投入工作" |
| 找不到工作 | 诚实但积极："当时的市场环境确实比较难，我用这段时间学了 XX 技能" |
| 什么都没做 | "花了一段时间调整状态和想清楚方向。现在想清楚了，这是我想做的事。" |

## 五、风险预案

### 模板

```
## 风险预案

### 关键假设
1. [假设 1]: 机器人行业的招聘需求持续增长（当前增长 409%，假设 12 个月内不逆转）
2. [假设 2]: 机械背景转机器人本体设计的技能映射被市场接受
3. [假设 3]: 3-6 个月能补齐 Critical Path 技能

### 如果假设不成立

→ 假设 1 不成立（行业遇冷）:
   Plan B: 转机电一体化工程师（更通用的中间岗，受行业波动影响小）
   或者回到汽车行业做底盘/动力总成的机械设计（运动学相关，技能部分重叠）

→ 假设 2 不成立（市场不接受机械背景）:
   Plan B: 先转机电一体化工程师做 1-2 年跳板，再投机器人岗
   或者考虑机器人的应用/集成方向（对机械背景更友好）

→ 假设 3 不成立（学习进度不如预期）:
   调整时间线：拉长到 12 个月
   或降级目标：从"机器人本体设计"降为"机器人集成应用"或"一般机电岗"

### 止损线

如果 [时间点/条件] 还没达到 [里程碑]:
  → 停下来重新评估。不要在一个方向死磕。
  → 回到 career-transition Step 4 重新探索方向。
```

## 六、输出时的注意事项

1. **每个行动必须具体到"在哪个平台做什么事"**——"学机器人"不是行动计划，"在 Coursera 上完成 Modern Robotics 第 1 周课程"才是
2. **故事线是真人真事的整理，不是模板填空**——根据用户的实际经历个性化调整
3. **第一个行动必须简单到不可能失败**——建立正反馈比完美计划更重要
4. **标注行动之间的依赖关系**——如果某个行动依赖前置条件，明确说明
5. **风险预案要具体**——不能说"如果不行就换方向"，要说"如果 3 个月内没拿到面试，换到哪个具体方向"
