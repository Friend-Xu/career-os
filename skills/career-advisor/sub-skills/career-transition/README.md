# career-transition — 职业转行分析

求职决策链的第二步：从技能审计、动机诊断、差距分析到行动计划，帮你评估"能不能转、怎么转、第一步做什么"。

## 与其它 skill 的关系

```
career-path                  →  "我该做什么方向？"
career-transition (本 skill) →  "怎么从现在的位置走到想去的位置？"
city-advisor                 →  "我该去哪个城市？"
company-screener             →  "这个城市有什么好公司？"
```

## 使用方式

直接在 Claude Code 中说：
- "我想转行，现在做机械设计想转机器人"
- "从 X 转到 Y 可行吗"
- "现在的工作不适合我"
- "转行怎么做，工作X年了想换赛道"
