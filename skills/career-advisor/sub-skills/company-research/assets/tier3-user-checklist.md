# 用户自查清单模板

报告输出完成后，根据用户职业和公司类型，生成定制化的自查清单。

---

## 模板

```markdown
---

## 你需要自己去确认的

以下渠道 AI 无法直接获取，建议你手动查一下：

### 员工真实口碑
- [ ] **脉脉 App** → 搜索 `[公司名]`，看员工匿名吐槽、薪资爆料、离职原因
- [ ] **小红书/抖音** → 搜索 `[公司名] 入职` 或 `[公司名] 工作体验`，看近期真实分享

### 法律与工商风险
- [ ] **天眼查/企查查** → 搜索 `[公司名]`，看司法风险、劳动纠纷数量、股东穿透
- [ ] **裁判文书网** (wenshu.court.gov.cn) → 搜索 `[公司名]`，看劳动纠纷判决书全文
- [ ] **信用中国** (creditchina.gov.cn) → 搜索 `[公司名]`，看行政处罚记录

### 薪资核实
- [ ] **Boss直聘/猎聘** → 搜 `[公司名] [岗位名]`，看当前招聘薪资区间
- [ ] **看准网/职友集** → 搜 `[公司名]`，看历史薪资数据和员工评分

### 面试相关
- [ ] **牛客网** → 搜索 `[公司名] [岗位名] 面经`，看最近面试者的真实反馈
```

---

## 职业定制追加

根据用户职业，追加特定建议：

### 研发/技术类追加
```markdown
- [ ] **GitHub/GitLab** → 搜 `[公司名]`，看是否有开源项目、技术博客
- [ ] 面试反问时直接问：技术栈、代码审查机制、研发团队规模
```

### 制造/工艺类追加
```markdown
- [ ] 面试反问时直接问：产线自动化程度、倒班制度、设备品牌和年代
- [ ] 如果可能，实地看一下工厂/车间环境
```

### 销售/市场类追加
```markdown
- [ ] 面试反问时直接问：底薪提成比例、客户是自己开拓还是分配、出差频率
- [ ] 搜 `[公司名] 客户` 看客户案例和行业口碑
```

### 外企追加
```markdown
- [ ] **Glassdoor** (glassdoor.com) → 搜索英文公司名，看海外员工评价
- [ ] **Indeed** → 搜索英文公司名，看薪资和面试经验
```

### 创业公司追加
```markdown
- [ ] **企查查/天眼查** → 看融资历史、股东背景、创始人履历
- [ ] **IT桔子/企名片** → 看融资轮次和金额是否真实
- [ ] 搜 `[创始人名]` 了解创始人背景和过往经历
```
