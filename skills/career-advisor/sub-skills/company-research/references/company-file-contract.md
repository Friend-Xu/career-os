# 公司档案落盘契约（引擎 companies/ 解析协议）

尽调完成后，除聊天输出报告外，还需将结论**落盘**为 `workspace/career-advisor/companies/{公司名}.md`，供引擎投影与 UI 公司卡消费。写完后**无需任何手动操作**——引擎监听该目录（add/change/unlink → 广播 → UI 自动重拉）；如引擎未运行，下次启动时扫描补齐。

## 文件结构

````markdown
# {公司名}

## 分析摘要

| 字段 | 值 |
|------|-----|
| city | 苏州 |
| industry | 工业自动化/机器人 |
| match_score | 74% |
| risk_level | 中 |
| source | 6 轮并行搜索（2026-08-07，company-research 尽调） |
| tags | design house, 外企, 项目制 |
| contacted | 否 |

---

## 尽调详情

{完整报告正文}
````

## 字段与值格式（引擎严格校验）

| 字段 | 必填 | 值格式 |
|------|:--:|--------|
| city | ✓ | 非空字符串。**写公司所在地**；JD 工作地与所在地不同时，工作地写进正文 |
| industry | ✓ | 非空字符串 |
| match_score | ✓ | **严格** `85%` 或 `8.2/10`——只许数值+百分号，**不许**带括号注释/来源说明/日期（注释放 source 或正文，带注释会解析失败、卡片该字段不显示） |
| risk_level | ✓ | `低` / `中` / `中高` / `高`（英文 low/medium/high 亦可） |
| source | ✓ | 非空字符串（搜索渠道 + 日期） |
| tags | ✓ | **逗号分隔**（半角 `,` 或全角 `，`），每项一个标签；用斜杠/空格分隔会被当成单个标签 |
| contacted | ✓ | `是` / `否`——**未联系写「否」**，不要写「-」（「-」虽被引擎解析为未联系，但「否」是规范写法） |
| park_id | 可选 | 数字（产业园区编号） |
| headcount | 可选 | 人数规模字符串 |

## 正文段落

- 报告正文放在 **`## 尽调详情`** 段之后（UI 详情视图从此段截取渲染；段落缺失时回退全文并重复展示摘要表）。
- 尚未尽调、仅建档占位的公司：摘要表其余字段填「-」即可（占位 = 待尽调，引擎按 invalid 标记、UI 显示待尽调）。

## 值域错误的影响（写错会怎样）

- 必填字段缺失/非法 → 档案 **invalid** → 公司卡显示「待尽调」、信息池图谱跳过该节点
- 字段值非法（如 match_score 带注释）→ **degraded** → 卡片该字段不显示（其他字段正常）
