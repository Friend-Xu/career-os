# 报告模板

使用说明：Step 5 输出报告时参考。先输出精简摘要，再输出完整报告。

---

## 精简摘要模板（200字以内，最先输出）

```markdown
## [公司名] 速判

**一句话**：[核心判断，基于用户职业定位的一句话总结]

**适合你的点**：
- [职业相关优势，最多3条]

**需要注意的**：
- [职业相关风险，最多3条]

**建议**：值得投 / 谨慎观望 / 不建议 — [一句话理由]
```

---

## 完整报告模板

```markdown
# [公司名]：求职背调报告

> 生成：[日期] | 职业视角：[用户岗位] | 阶段：[海投/面试中/拿offer/纯了解] | 来源：[N] | 置信度：[高/中/低]

---

## 0. 职业匹配度速评

> 以下分析针对 **[用户岗位]** 岗位

| 维度 | 评价 | 说明 |
|------|:----:|------|
| 岗位是否核心职能 | ✓/△/✗ | [理由] |
| 技术/能力成长空间 | ✓/△/✗ | [理由] |
| 薪资行业对标 | ✓/△/✗ | [理由] |
| 稳定性风险 | ✓/△/✗ | [理由] |

---

## 1. 公司基本面

- **全称**：[公司全称]
- **成立**：[时间]，[城市]
- **规模**：[注册资本]，[员工数]
- **业务**：[主营业务，一段话]
- **产品**：[主要产品线、型号数]
- **模式**：[ODM/自主品牌/代工]
- **资质**：[专精特新/高新企业等荣誉]

---

## 2. 财务与资本

[上市/拟IPO公司]
- 近三年营收/净利润/毛利率趋势
- 研发投入金额和占比
- IPO状态（辅导中/已申报/过会/撤回/已上市）
- 募集资金用途

[非上市公司]
- 注册资本、股东、对外投资
- 标注：非上市公司，财务数据未公开

---

## 3. 职业视角分析

> 以下专门针对 **[用户岗位]** 岗位

### 3.1 岗位是否核心职能

[公司主营业务与该岗位的匹配度分析]
[公司在招聘中对岗位的定位描述]

### 3.2 技术/能力成长

[技术/研发/制造类]
- 技术路线、核心产品技术含量
- 研发团队规模和背景、专利情况
- 行业技术趋势（上升/瓶颈/淘汰）

[销售/市场类]
- 技术型销售还是纯商务
- 客户资源质量
- 出差频率和区域

### 3.3 薪资对标

- 该岗位行业薪资区间
- 公司薪资在行业中的位置
- 隐性福利（公积金、年终奖、加班费）

### 3.4 面试经验
[如搜到面经则输出]
- 面试流程和轮次
- 常见问题
- 面试体验评价

### 3.5 面试反问十问

> 以下是基于职业定位生成的面试反问，帮助你在面试中获取关键信息。

| # | 反问 | 你在了解什么 |
|---|------|-------------|
| 1 | [根据岗位生成] | [你想知道的] |
| ... | ... | ... |
| 10 | [最后一问：痛点探测] | [观察反应比回答更重要] |

**回答信号参考**：

| 信号 | 绿（好迹象） | 黄（需追问） | 红（警戒） |
|------|:----------:|:----------:|:--------:|
| 回答速度 | 直接、具体、有细节 | 犹豫但最终给出具体回答 | 长时间停顿后模板化回答 |
| 坦诚度 | 主动提到不足和改进方向 | 追问后才提不足 | 回避问题或明显美化 |
| 一致性 | 多个面试官回答一致 | 小细节有出入 | 核心信息明显矛盾 |
```

```markdown
| 薪资行业对标 | | | |
| 稳定性 | | | |
```
