# 搜索执行手册

## 三层数据源分级

### Tier 1 — 必查（100%覆盖，完全公开）

搜索引擎直接可索引的公开信息。

| 数据源 | 获取方式 | 典型可获取内容 |
|--------|----------|---------------|
| 公司官网 | WebFetch | 主营业务、产品、团队、新闻 |
| 百度百科 | WebSearch + WebFetch | 工商基本信息、荣誉、历史沿革 |
| 交易所公告（深交所/上交所） | WebSearch + WebFetch | IPO招股书、年报、问询回复 |
| 巨潮资讯网 cninfo.com.cn | WebSearch | 上市公司公告全文 |
| 财经网站（东方财富、新浪财经） | WebSearch + WebFetch | 财务数据、IPO进度 |
| 政府公示（专精特新名单等） | WebSearch | 资质认定 |

搜索策略：`WebSearch` + `Exa web_search_exa` 双源并行。

### Tier 2 — 尽力（搜索引擎可能收录，成功率因公司而异）

| 数据源 | 获取方式 | 典型可获取内容 | 成功率 |
|--------|----------|---------------|:------:|
| 知乎 | WebSearch 搜缓存页 | 员工评价、面试经验 | 中 |
| 看准网/职友集 | WebSearch 搜缓存页 | 员工评分、薪资 | 中-低 |
| 牛客网 | WebSearch 搜缓存页 | 面经、薪资爆料 | 中 |
| 信用中国 creditchina.gov.cn | WebFetch | 行政处罚记录 | 中 |
| 国家企业信用信息公示系统 | WebSearch | 工商登记、处罚 | 低（反爬强） |
| 招聘平台（Boss直聘/猎聘） | WebSearch 搜缓存页 | 岗位描述、薪资区间 | 低（登录墙） |

注意：Tier 2 的结果标注"可能不完整，建议自行验证"。

### Tier 3 — 指路（AI无法获取，告诉用户自己去查）

| 渠道 | 用户需要做什么 |
|------|---------------|
| 脉脉 | App内搜公司名，看员工匿名吐槽和薪资爆料 |
| 天眼查/企查查 | 搜索公司名，看司法风险、股东穿透（VIP功能可能需要付费） |
| 裁判文书网 wenshu.court.gov.cn | 搜索公司名，看劳动纠纷判决书全文 |
| 小红书/抖音 | 搜索"公司名 入职"看近期真实入职体验 |

## 六轮并行搜索模板

对于每一轮，同时执行 `WebSearch`（中文）+ `Exa web_search_exa`（中英文）。

### 第1轮：公司基本面

```
WebSearch:  "[公司名] 公司简介 主营业务 成立 员工"
WebSearch:  "[公司名] 百度百科"
Exa:        "[公司名] company overview business products"
```

### 第2轮：财务与上市状态

```
WebSearch:  "[公司名] IPO 上市 营收 净利润 招股说明书"
WebSearch:  "[公司名] 年报 财务 创业板 科创板 深交所"
Exa:        "[公司名] IPO revenue financial annual report"
```

若公司已上市/拟IPO：
- 加搜 `"[公司名] 募集资金 募投项目"`
- 加搜 `"[公司名] 审核问询 反馈意见"`

若非上市公司：
- 加搜 `"[公司名] 融资 估值 投资"`

### 第3轮：员工口碑

```
WebSearch:  "[公司名] 员工评价 怎么样 加班"
WebSearch:  "[公司名] 知乎 评价 工作体验"
WebSearch:  "[公司名] 看准网 员工 薪资"
Exa:        "[公司名] employee review work culture"
```

### 第4轮：薪资与面经（职业驱动）

根据用户职业定位动态生成关键词。默认：

```
WebSearch:  "[公司名] [岗位关键词] 薪资 面试 面经"
WebSearch:  "[公司名] [岗位关键词] 牛客网 offer"
Exa:        "[公司名] [role] interview salary offer"
```

岗位关键词提取规则：
- 用户说"机械工程师" → 关键词"机械工程师"、"结构设计"、"机械研发"
- 用户说"Java后端" → 关键词"Java"、"后端开发"、"软件工程师"
- 用户说"销售" → 关键词"销售"、"销售工程师"、"客户经理"

### 第5轮：法律风险

```
WebSearch:  "[公司名] 劳动仲裁 劳动纠纷"
WebSearch:  "[公司名] 行政处罚 失信 被执行人"
WebSearch:  "[公司名] 裁判文书 判决"
WebFetch:   https://www.creditchina.gov.cn 搜索[公司名]
```

### 第6轮：行业与竞争

```
WebSearch:  "[行业关键词] 市场规模 竞争格局 排名"
WebSearch:  "[公司名] 竞争对手 市场份额"
WebSearch:  "[公司名] 行业地位 专精特新"
Exa:        "[industry] market size competitors [company]"
```

## 公司类型适配

| 公司类型 | 搜索调整 | 预期置信度 |
|----------|---------|:----------:|
| **上市公司** | 深度读年报/公告，财务数据完整 | 高 |
| **拟IPO/新三板** | 读招股书（数据可能已旧），查辅导进度 | 中-高 |
| **中小民企** | 加大口碑搜索权重，减少财务搜索 | 中 |
| **外资企业** | 加搜 Glassdoor/Indeed 英文评价 | 中 |
| **创业公司** | 搜融资轮次+创始人背景+团队规模 | 低-中 |
| **国企/央企** | 搜编制/合同制区别+福利体系+稳定性 | 中 |

## 深度阅读优先级

搜索完成后，从结果中选 3-5 篇全文阅读：

1. **最优先**：招股说明书/年报（信息密度最高、可信度最高）
2. **次优先**：行业深度报道、财经媒体分析
3. **补充**：牛客网面经、知乎高赞评价（标注主观/个人）
