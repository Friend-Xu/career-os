# 对抗验证

报告输出前，以反方视角逐条检查。发现的问题修正后再输出。

---

## 检查清单

### 事实与推断

- [ ] 是否把管理层叙事/公关稿当成了事实？
- [ ] 是否把相关性当成了因果？
- [ ] 是否混用了财年、币种、会计口径或母子公司数据？
- [ ] 是否用单一指标推出强结论？
- [ ] 是否存在能推翻当前判断的反证？
- [ ] 旧数据是否标注了年份？

### 信源质量

- [ ] 匿名评价是否标注了"仅供参考"？
- [ ] 官方文件是否标注了"可信"？
- [ ] 查不到的信息是否诚实标注"未查到/未公开"？
- [ ] 是否存在"听起来有道理但没数据支撑"的断言？

### 职业视角一致性

- [ ] 报告是否始终围绕用户职业定位组织？
- [ ] 岗位核心度判断是否基于主营业务分析？
- [ ] 薪资对标是否区分了应届/有经验/资深？

### 信息缺口

- [ ] 本次搜索是否存在明显未覆盖的维度？
- [ ] 若 WebSearch 不可用，是否标注了数据源局限？
- [ ] 非上市公司是否避免编造精确财务数据？

---

## 对抗角度

完成上述清单后，额外从以下角度挑战报告结论：

1. **乐观偏差**：如果我是这家公司的 HR/PR，我会怎么反驳这份报告？
2. **时效偏差**：报告引用的数据最早是哪一年的？旧数据是否还在有效期？
3. **样本偏差**：员工评价来源是否过于集中？是否存在极端偏差？

---

## 修正规则

- 发现事实错误 → 直接修正
- 发现推断过度 → 降低语气强度，添加限定词
- 发现信息缺口 → 标注"本次搜索未覆盖"，移入 Tier 3 自查清单
- 发现关键反证 → 在报告中同时呈现正反两面
