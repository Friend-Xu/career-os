# 搜索执行手册

4路并行搜索 + 打分模型 + 行业分桶规则。

---

## 核心原则

1. **不预设行业**：从职业反推行业簇，而非限定单一行业
2. **信号驱动**：公司不需要全名搜到才算，捕获一个强信号即可入选
3. **4路并行**：资质 + 融资 + 职业反推 + 风险初筛，前3路用 Agent 并行派发

---

## 搜索执行

### 第 1 路：资质信号

搜索专精特新小巨人、独角兽、瞪羚企业、高新技术企业名单。

```
搜索模板（每个 2-3 个变体）:
  "[城市] 专精特新 小巨人 [行业关键词]"
  "[城市] 独角兽 潜在独角兽 [行业关键词]"
  "[省份] 瞪羚企业 [行业关键词]"
  "[城市] 高新技术企业 [行业关键词]"
```

优先级：国家级专精特新 > 省级专精特新 > 其他

### 第 2 路：融资信号

搜索近3年融资事件。

```
搜索模板（每个 2-3 个变体）:
  "[城市] [行业关键词] 融资 B轮 C轮 2024 2025"
  "[城市] 医疗器械 融资 数亿 高瓴 红杉 元禾"
  "[城市] [行业关键词] 上市辅导 IPO"
```

知名投资方识别：高瓴创投、红杉中国、启明创投、元禾控股、毅达资本、深创投、达晨财智、软银中国、IDG、君联资本、夏尔巴投资、苏高新金控

### 第 3 路：职业反推（核心创新）

不预设行业，从岗位关键词反找公司。搜索"公司在招这个岗位"的信号。

```
搜索模板（每个 2-3 个变体）:
  "[城市] [搜索关键词] 招聘"
  "[城市] [搜索关键词] 研发工程师 -外包 -劳务 -派遣"
  "[职业名] [城市] 公司 招聘 2025"
```

搜索结果中带公司名的链接本身就是有效信号。"有招聘"就是筛选条件。

### 第 4 路：风险初筛

对前3路收集到的公司名，批量搜索风险信号。

```
搜索模板:
  "[公司名] 经营异常"
  "[公司名] 失信 被执行人"
  "[公司名] 劳动仲裁 劳动争议"
```

## 打分模型

| 信号 | 分值 | 说明 |
|------|:--:|------|
| 国家级专精特新小巨人 | +3 | 工信部公示，全国约 1.2 万家 |
| 省级专精特新 / 潜在独角兽 | +2 | 各省科技厅/长城战略咨询发布 |
| 瞪羚企业 / 高新技术企业 | +1 | — |
| B 轮及以上融资（近 3 年） | +2 | 2023-2026，A 轮+1 |
| 知名投资方站台 | +1 | 高瓴/红杉/元禾/毅达/深创投/达晨/启明/软银等 |
| 产品/业务与职业强相关 | +2 | 机械岗 → 精密传动/结构设计/非标/模具等 |
| 搜索结果中出现招聘关联 | +1 | 有招聘信号就加分 |
| 经营异常 | -3 | 存在即扣分 |
| 失信/被执行人 | 标红 | 不计分，直接标记"⚠ 高风险" |

---

## 分层展示规则

| 分数 | 层级 | 展示方式 |
|------|------|------|
| ≥ 5 分 | 强信号 | 默认展开、置顶，高亮推荐 |
| 3-4 分 | 中等信号 | `<details>` 折叠，按行业分桶 |
| < 3 分 | 弱信号 | 不展示 |

---

## 行业分桶规则

根据 career-industry-map.md 的行业桶标签自动归类。

- 一家公司可同时属于多个桶（如骨科手术机器人 → "医疗器械" + "机器人/自动化"）
- 桶排序：强信号公司数多的桶排前面
- 每个桶内：按信号分数降序排列

---

## 数据标注规则

每条信号标注来源类型：

| 标注 | 含义 |
|------|------|
| `[工信部·2024]` | 工信部公示名单 |
| `[36氪·2025.03]` | 媒体报道的融资事件 |
| `[天眼查]` | 工商/财务/风险数据 |
| `[搜索结果]` | 搜索引擎搜索结果中的关联信号 |
| `[IT桔子·2025]` | 融资数据库 |
