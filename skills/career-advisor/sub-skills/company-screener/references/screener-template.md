## 表格列说明

| 列 | 格式 | 示例 |
|------|------|------|
| # | 数字 | 1 |
| 公司 | 全称 | 敏捷医疗科技（苏州）有限公司 |
| 地点 | 城市 | 苏州 |
| 产品/方向 | 一句话 | 腔镜手术机器人 |
| 信号 | 信号标签拼接 | `B轮数亿·专精特新·元禾` |
| 对口 | ★★★★★ ~ ★☆☆☆☆ | ★★★★★ |
| 备注 | 一句话风险/亮点 | 刚扭亏为盈 `[36氪·2025.04]` |

---

## 信号标签速查

| 标签格式 | 含义 |
|------|------|
| `B轮数亿` | B 轮融资数亿元 |
| `B+轮近亿` | B+ 轮近亿元 |
| `专精特新` | 国家级专精特新小巨人 |
| `省专精特新` | 省级专精特新 |
| `独角兽` | 中国独角兽 |
| `潜在独角兽` | 中国/省级潜在独角兽 |
| `瞪羚` | 瞪羚企业 |
| `高新` | 高新技术企业 |
| `IPO辅导` | 已启动上市辅导 |
| `高瓴` `红杉` `元禾` `毅达` `深创投` 等 | 知名投资方（最多列 2 个） |
| `有招聘` | 搜索结果中出现岗位关联 |

---

## 备注格式

```
—                                          → 无特别事项
刚扭亏 `[36氪·2025.04]`                     → 附来源和年份
⚠ 失信被执行人 `[天眼查]`                    → 高风险标记
无商业化产品 `[公司官网]`                     → 需注意
```
