# 资质名单沉淀格式契约

> knowledge 资产格式契约——`workspace/career-advisor/knowledge/资质名单-{城市}-{年份}.md`。
> 契约依据：Company-Leaderboard-Contract-v0.1 §2.4。
> 定位：把官方公示的资质名单沉淀为本地可复用知识，供 screener 第 1 路资质信号零搜索成本命中。

---

## 定位与生命周期

- **Producer**：Agent 解析官方公示页（工信部 / 省工信厅 / 科技部门），**每条必带来源链接**
- **刷新**：年度刷新，非实时 API（以官方公示批次为准，不追实时榜单）
- **消费**：company-screener 第 1 路资质信号先读沉淀名单；未覆盖城市再走搜索模板
  （`sub-skills/company-screener/references/screener-search-strategy.md` 第 1 路）
- **所有权**：内容型知识资产（Agent 生成）；命中后登记进候选池 `signals` 时带来源标注

---

## 文件路径与命名

| 项 | 规则 | 示例 |
|----|------|------|
| 目录 | `workspace/career-advisor/knowledge/` | — |
| 文件名 | `资质名单-{城市}-{年份}.md` | `资质名单-城市A-2026.md` |
| 城市 | 官方公示城市名 | 城市A |
| 年份 | 公示批次年份（YYYY） | 2026 |

- 一个文件一个城市；同城不同批次追加行（批次年份列区分），不重复建档

---

## 文件格式

### 标题

```markdown
# 资质名单 · 城市A · 2026 年批次
```

### 资质名单表

```markdown
## 资质名单

| 公司 | 城市 | 资质类型 | 公示来源链接 | 批次年份 |
|------|------|---------|-------------|---------|
| 示例公司A | 城市A | 小巨人 | https://example.gov.cn/qualification/2026/01 | 2026 |
```

### 列说明

| 列 | 必填 | 说明 |
|----|:--:|------|
| 公司 | 是 | 官方公示全称 |
| 城市 | 是 | 公示城市 |
| 资质类型 | 是 | 枚举见下节 |
| 公示来源链接 | 是 | 官方公示页链接（可追溯前提） |
| 批次年份 | 是 | 公示批次年份 |

---

## 资质类型枚举

| 资质类型 | 发布方（示例） | 说明 |
|---------|--------------|------|
| 小巨人 | 工信部（国家级）/ 省工信厅 | 专精特新「小巨人」企业 |
| 高新 | 科技部门 | 高新技术企业 |
| 瞪羚 | 省/市科技部门 | 瞪羚企业 |
| 独角兽 | 官方/权威机构公示 | 中国独角兽企业 |
| 潜在独角兽 | 官方/权威机构公示 | 潜在独角兽企业 |

- 枚举外资质类型不沉淀进本表（避免口径漂移）

---

## Producer 纪律

1. **每条必带来源链接**——公示来源链接缺失的行不沉淀
2. 解析官方公示页原文，不转述媒体报道（媒体稿仅作线索，不直接沉淀）
3. 公司名用官方公示全称
4. 批次年份 = 公示批次年份，与抓取日期区分（抓取日期不入表）
5. 年度刷新：新批次公示后追加行；同公司同资质同批次去重
6. 不编造公司名/资质；检索不到即不沉淀该行

---

## 消费方（screener 第 1 路）

1. Read `workspace/career-advisor/knowledge/资质名单-{城市}-{年份}.md`
2. 命中公司 → 资质信号登记进候选池 `signals`（tag / source / date 对齐候选池登记契约）：
   ```json
   {"tag":"专精特新","source":"[工信部·2026]","date":"2026"}
   ```
3. 未覆盖城市 → 走搜索模板（screener-search-strategy.md 第 1 路），搜索命中的资质信号同样带来源

**资质类型 → 信号 tag 映射**（沿用 screener 信号标签体系，见 screener-template.md 信号标签速查）：

| 资质类型（沉淀名单列） | 候选池 signals.tag |
|----------------------|-------------------|
| 小巨人 | 专精特新 |
| 高新 | 高新 |
| 瞪羚 | 瞪羚 |
| 独角兽 | 独角兽 |
| 潜在独角兽 | 潜在独角兽 |
